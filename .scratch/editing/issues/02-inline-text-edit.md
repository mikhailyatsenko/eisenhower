# Правка текста на месте

Type: prototype
Status: resolved
Blocked by: 01

## Question

Как править текст задачи без диалога Edit: прямо на карточке в матрице и в строке List view? Как войти в правку (клик по выделенной задаче, `E`/`Enter`, кнопка в панели), как сохранить и отменить (Enter, Esc, blur), что с ошибкой длины (200 символов), с панелью действий и фокусом во время правки, как это выглядит на телефоне. Прототип вариантов в приложении, выбор — с пользователем.

## Answer

Вариант **B «Панель превращается»**, выбран вместе с пользователем по прототипу в приложении. Прототип — ветка `prototype/inline-text-edit`, коммит `9c7422d`, `?variant=A|B|C`: A — поле прямо в карточке, панель прячется; C — текст выбранной задачи всегда поле, без режима.

- **Как в Deadline:** панель действий сама становится полем правки, так же как для срока в [тикете 03](03-deadline-button.md). Поверх ничего не открывается.
- **Вход:** кнопка Edit в панели, `E` или `Enter` на выбранной задаче. Весь текст в поле сразу выделен. Повторный клик по задаче, как и раньше, снимает выделение.
- **Панель на десктопе:** одна строка: «← Back», поле шириной до 40rem (`min(40rem, 100vw − 16rem)`), «Save» с подсказкой `Enter`. Поле растёт по высоте и показывает длинный текст целиком (до `max-h-40`, дальше прокрутка). Back и Save выровнены по верхнему краю поля.
- **Панель на телефоне:** в верхней строке «← Back», «Edit text», «Save», под ней поле на всю ширину. Save стоит над полем, чтобы экранная клавиатура его не закрывала. Панель поднимается над клавиатурой по `visualViewport`. На настоящем iOS не проверено, только в эмуляции.
- **Карточка во время правки:** обведена пунктиром и показывает черновик вживую, пустой — «(empty)».
- **Сохранить и отменить:** `Enter` или Save сохраняют. `Esc` или Back отменяют без сохранения. После любого из них фокус возвращается на задачу, выделение остаётся. Выбор другой задачи или снятие выделения закрывают правку без сохранения. Клавиши страницы (C, 1–4, Del…) в поле не работают.
- **Текст:** одна строка по смыслу: переносы при вставке превращаются в пробелы, Enter перенос не ставит. Длина ограничена 200 символами (`maxLength`), счётчик `NNN/200` появляется с 170 и краснеет на 200. Пустой текст (после trim) не сохраняется: Save показывает «A task needs some text», поле остаётся открытым. Неизменённый текст не пишется. Срок и квадрант не меняются.
- **Для реализации:** в прототипе поле — `TextEditPanelPrototype` в `ActionToolbar`, черновик — в общем сторе, чтобы карточка его видела. Правка `useDeselectOnPageClick` (пропуск кликов по отсоединённым узлам) нужна была только варианту A, для B не нужна.

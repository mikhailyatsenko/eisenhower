# Кнопка «Deadline» в панели действий

Type: prototype
Status: resolved
Blocked by: 01

## Question

Как выглядит и ведёт себя отдельная кнопка дедлайна в панели действий выбранной задачи (установка и правка срока): что написано на кнопке (слово или текущий срок), что она открывает (поповер с чипами и датой из `DeadlineFields`, лист снизу на телефоне, что-то ещё), сохраняется ли выбор сразу или по кнопке, где она стоит в ряду Complete / Edit / Delete на телефоне и в строке на десктопе. Прототип вариантов в приложении, выбор — с пользователем. Найденный способ задать срок должен годиться и для добавления задачи.

## Answer

Вариант **B «Панель превращается»**, выбран вместе с пользователем по прототипу в приложении. Прототип — ветка `prototype/deadline-button`, коммит `e93cb05`, `?variant=A|B|C`: A — поповер/лист снизу, C — системный пикер сразу.

- **Надпись:** на кнопке сам срок («📅 Sun, Sep 27», цвет по статусу: просрочен, сегодня, скоро); без срока — «Deadline».
- **Место:** на десктопе — в строке после Move to, перед Delete; на телефоне — отдельная строка на всю ширину под Complete / Edit / Delete: «Deadline … Sun, Sep 27 ›», без срока «None».
- **Что открывает:** ничего поверх. Панель действий сама становится выбором срока: «← Back», чипы Today / Tomorrow / This weekend / Next week / No deadline, поле даты, «+ Time», «Set». На телефоне то же в панели, чипы сеткой 2×2 с датой под названием. Back, Esc и сохранение возвращают обычную панель, фокус — на кнопку Deadline.
- **Сохранение:** чип сохраняет сразу, одно действие после открытия; своя дата с необязательным временем — по «Set» или Enter.
- **Клавиши:** `D` открывает (у нас свободна; `T` тоже свободна, но выбрана `D`); в выборе `T` Today, `M` Tomorrow, `W` This weekend, `X` Next week, `Del`/`Backspace` без срока, `Esc` назад. От выбранной задачи до срока — 2 нажатия. Клавиши страницы (C, E, 1–4…) во время выбора не срабатывают.
- **Десктопная строка:** у поля даты нет видимой подписи «Date» (формат `dd.mm.yyyy` понятен и так), подпись остаётся для скринридера; поле, «Set» и чипы выровнены по центру. На телефоне подпись видна: там поле стоит отдельной строкой.
- **Для добавления (тикет 04):** тот же набор — чипы, дата, время, Set — годится рядом с inline-полем; компонент выбора в прототипе один (`DeadlineChooser`).
- Замечено: когда день чипа совпадает (сегодня воскресенье — Today и This weekend), нажаты оба чипа, как и в нынешнем `DeadlineFields`.

# Добавление задачи сразу со сроком

Type: prototype
Status: resolved
Blocked by: 01, 03

## Question

Как задать срок прямо при добавлении через inline-поле квадранта и секции List view, без полной формы «New task»: кнопка срока рядом с полем (с тем же выбором срока, что у кнопки «Deadline»), разбор срока из текста или оба? Сколько действий от «+» до задачи со сроком, как это на телефоне и с клавиатуры. Прототип вариантов в приложении, выбор — с пользователем.

## Answer

Вариант **D «Лента срока в панели»** с кнопкой Add, выбран вместе с пользователем по прототипу в приложении. Прототип — ветка `prototype/add-with-deadline`, `?variant=A|B|C|D`: A — кнопка 📅 у поля, открывающая выбор тикета 03 под полем; B — разбор срока из текста с подсветкой и отменой; C — оба.

- **Лента вместо панели:** пока открыто inline-поле квадранта или секции List view, внизу, на месте панели действий, стоит лента срока для набираемой задачи: чипы Today / Tomorrow / This weekend / Next week / No deadline, поле даты, «+ Time», кнопка Add. Лишнего нажатия «открыть выбор срока» нет.
- **Add:** добавляет задачу так же, как Enter в поле. Без срока надпись «Add without deadline», со сроком — «Add · Thu, Oct 15». Пока текст пуст, кнопка неактивна. После добавления фокус возвращается в поле.
- **Без Set:** чип, дата и время применяются сразу при выборе, фокус при вводе даты остаётся в поле даты. Enter в поле даты или времени добавляет задачу. Отдельная кнопка Set в ленте дублировала бы Add.
- **«+ Time»** всегда стоит рядом с полем даты, и когда дата не выбрана. Без даты он ставит срок на сегодня, 09:00.
- **Клавиатура:** Tab из поля переводит фокус в ленту, на нажатый чип; там `T` / `M` / `W` / `X` / `Del`, как в тикете 03. После выбора чипа фокус возвращается в поле, дальше Enter. Esc в ленте возвращает в поле.
- **Число действий от «+»:** без срока — «+» → текст → Enter (3); со сроком — «+» → текст → чип → Enter или Add (4); с клавиатуры — `1–4` → текст → Tab → `M` → Enter.
- **Телефон:** лента прижата к низу и поднимается над клавиатурой по `visualViewport`. В верхней строке «Deadline · new task in <квадрант>» и Add, под ней чипы и дата с переносом строк, без горизонтальной прокрутки. На настоящем iOS не проверено, только в эмуляции.
- **Срок сбрасывается** после каждого добавления: следующая задача начинается без срока.
- **Разбора срока из текста нет.** В прототипе B/C он давал ложные срабатывания («Sat down with Anna» → суббота) и понимает только английский. Если понадобится, это отдельная работа.
- **Для реализации:** закрытие пустого поля при потере фокуса надо считать по полю и ленте вместе: переход в ленту поле не закрывает. Тест `inlineAdd.test` «closes an empty field when focus leaves it» на ветке прототипа поэтому падает, коммит сделан с `--no-verify`. На десктопе лента заходит под плавающую кнопку «New task»; её судьба — в [тикете 05](05-edit-dialog-and-float-button.md).

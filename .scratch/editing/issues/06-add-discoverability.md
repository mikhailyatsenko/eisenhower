# Как новичок находит добавление без New task

Type: prototype
Status: resolved
Blocked by: 04, 05

## Question

Без плавающей кнопки «New task» ([тикет 05](05-edit-dialog-and-float-button.md)) как новичок узнаёт, что задачу добавляют в квадранте, на пустой и на непустой матрице, на телефоне и на десктопе? Хватает ли «Click to add a task» / «Tap to add» в пустых квадрантах, «+» в шапке и подсказки «click empty space to add» (сейчас только для мыши и до первого раза), или «+» нужна подпись, подсказка на пустой матрице, что-то ещё? Постоянному пользователю это не должно мешать. Прототип вариантов в приложении, выбор — с пользователем.

## Answer

Вариант **B «+ Add в шапке»**, выбран вместе с пользователем по прототипу в приложении. Прототип — ветка `prototype/add-discoverability`, `?variant=A|B|C|D|E`: A — как есть, только без «New task»; C — строка «+ Add task» в конце каждого непустого квадранта; D — подсказка над матрицей и пульсирующий «+» до первого добавления; E — неплавающая кнопка «Add task N» над матрицей.

- **«+» в шапке квадранта и секции List view получает подпись:** это пилюля «+ Add» с рамкой, на десктопе и на телефоне одинаково, видна всегда, а не только новичку. Доступное имя прежнее — «Add a task to <квадрант>» (видимое «Add» плюс невидимый хвост). Цель на телефоне — 44px, на десктопе — строка шапки.
- **Подсказка «click empty space to add» убирается.** Её роль берёт на себя подпись. Клик по пустому месту по-прежнему открывает поле, просто о нём больше не говорят. Вместе с подсказкой уходят `EmptySpaceHint`, `hasAddedByEmptySpace` в `uiStore`, `isByEmptySpace` у `inlineAdd` и `openInlineAddByEmptySpaceAction`, если он остаётся нужен только ради флага. Проверить поиском при реализации.
- **Пустой квадрант не меняется:** примеры и «Click to add a task» / «Tap to add» остаются.
- **Почему не другие варианты:** C занимает высоту в тесной ячейке и дублирует «Click to add a task». D показывается один раз, и его легко закрыть не читая. E снова делает глобальную кнопку, которая угадывает квадрант, а по [тикету 05](05-edit-dialog-and-float-button.md) квадрант задаётся местом, где открыто поле.
- **Срез:** подпись выходит в том же срезе, где уходит `FloatButton`: ни в каком срезе новичок не остаётся без заметного пути добавления.
- **Не проверено в прототипе:** свёрнутые секции List view, шапка квадранта во весь экран на телефоне, узкие окна 640–800px, где пилюля и «click empty space» раньше делили строку. Проверить при реализации, в том числе axe.

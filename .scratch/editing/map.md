# Быстрая правка и добавление

Label: wayfinder:map

## Destination

Спека релиза `.scratch/ux-r5/spec.md` в формате ux-r4 (срезы с буквами), готовая для `/mattpocock-skills:to-tickets`: правка текста и дедлайна задачи в меньшее число действий, добавление задачи сразу со сроком без плавающей кнопки «New task».

## Notes

- Продолжение UI-обновления после ux-r4 ([аудит](../ui-ux-audit/map.md), [спека R4](../ux-r4/spec.md)).
- В scope: правка текста и дедлайна (квадрант — только если путается с правкой), добавление задачи, судьба диалога Edit и плавающей кнопки `FloatButton`. Добавление без плавающей кнопки должно оставаться удобным, дедлайн задаётся сразу при создании, если нужен.
- Главный пользователь — постоянный: «меньше действий» — про него. Новичок не теряет понятности. Телефон и десктоп наравне.
- Планка ux-r4: у каждого действия клавиша, axe-тесты, строки в `docs/agents/a11y-checklist.md`.
- Исходная точка: сейчас текст, дедлайн и квадрант меняются только в диалоге Edit; inline-поле квадранта (`+`, клик по пустому месту, `1–4`, `N`) принимает только текст; полная форма со сроком и выбором квадранта — только за `FloatButton`.
- Прототипы — веткой `prototype/<name>` с вариантами прямо в приложении, как `prototype/deadlines` в ux-r4.
- Словарь: `CONTEXT.md`. Для grilling-задач вызывать скиллы `grilling` и `domain-modeling`, для prototype-задач — `prototype`, для research — `research`.

## Decisions so far

- [Как другие приложения делают быструю правку и добавление со сроком](issues/01-quick-edit-research.md): срок — поповер с быстрыми вариантами за одну клавишу/клик из выбранной задачи (2 действия), текст — на месте или в деталях без модального диалога, добавление со сроком — кнопка срока у поля (разбор текста только с подсветкой и отменой), плавающей «+» на десктопе нет ни у кого.
- [Кнопка «Deadline» в панели действий](issues/03-deadline-button.md): вариант B — на кнопке сам срок, панель сама превращается в выбор (чипы сохраняют сразу, своя дата по Set), клавиша `D`, затем `T`/`M`/`W`/`X`/`Del`; на телефоне отдельная строка под рядом действий.
- [Правка текста на месте](issues/02-inline-text-edit.md): вариант B — панель сама превращается в поле (Back, поле, Save), как у Deadline; вход Edit / `E` / `Enter`, `Enter` сохраняет, `Esc` отменяет, карточка показывает черновик; на телефоне Save в верхней строке над полем.

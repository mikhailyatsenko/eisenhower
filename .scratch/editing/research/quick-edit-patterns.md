# Как другие приложения делают быструю правку и добавление со сроком

Исследование по тикету `.scratch/editing/issues/01-quick-edit-research.md`. Дата: 2026-09-27.

Источники: help center и документация Todoist, TickTick, Cultured Code (Things), Microsoft Support (To Do), Linear docs и changelog. Страницы TickTick рендерятся скриптом, поэтому их текст взят из встроенных данных страницы (`__NEXT_DATA__`) через `curl`. Живой проход по приложениям не делался. Где утверждение не подтверждено первичным источником, стоит пометка **[доверие: среднее]** или **[доверие: низкое]** с объяснением. Число действий считается от выбранной (или наведённой) задачи или от нажатия «добавить» до готового результата. Набор текста считается одним действием, Enter для подтверждения — отдельным.

## 1. Правка текста задачи

**Два подхода: правка на месте и правка в панели/окне деталей. Отдельного модального диалога «Edit» ради одного названия нет ни у кого.**

- **Linear — правка на месте.** «You can edit an issue title or description by clicking directly on the title or description and editing inline.» ([Linear, Edit issues](https://linear.app/docs/editing-issues)). Место — открытая задача, не строка списка. Из списка: выбрать задачу, открыть (Enter), кликнуть по заголовку.
- **Things — задача раскрывается на месте.** «When you open a to-do, it smoothly transforms into a clear white piece of paper» ([Things, Features](https://culturedcode.com/things/features/)). Клавиши: «Open selected item — Return», «Save and close item — ⌘ Cmd Return» ([Things, Keyboard Shortcuts for Mac](https://culturedcode.com/things/support/articles/2785159/)). То есть вход — Return/двойной клик, выход — `Cmd+Return` или клик мимо **[доверие: среднее для двойного клика и клика мимо: это поведение Mac-приложения, в статье явно описаны только Return и Cmd+Return]**. Карточка раскрывается в самом списке, соседи сдвигаются, отдельного окна нет.
- **Todoist — task view.** «Click a task to open the task view where you can modify the task name or add a description»; на телефоне «Open a task and tap the task name to edit it» ([Todoist, Introduction to tasks](https://www.todoist.com/help/articles/introduction-to-tasks-080OAXric)). Действий: клик по задаче → клик по названию → ввод → Esc («Close task view — Esc»). Клавиши: `Enter` — «Open task view», `Cmd/Ctrl+E` — «Edit task», `Cmd/Ctrl+Enter` — «Save edits», `Esc` — «Dismiss/Cancel» ([Todoist, Keyboard shortcuts](https://www.todoist.com/help/articles/use-keyboard-shortcuts-in-todoist-Wyovn2)). «Edit task» на вебе открывает редактор прямо в строке списка (то же поле, что «Add task», с кнопками Date/Priority) **[доверие: среднее: по памяти о приложении; справка называет клавишу, но не описывает, где открывается редактор]**.
- **Microsoft To Do — панель деталей.** «To rename a task, select the task to open its detail view. Once in the detail view, you can select the task's title. A cursor will appear in the task title field» ([Microsoft, Create, edit, delete, and restore tasks](https://support.microsoft.com/en-us/todo/create-edit-delete-and-restore-tasks)). Действий: 2 клика + ввод. Клавиши для переименования в официальном списке нет ([Microsoft, Keyboard shortcuts in To Do](https://support.microsoft.com/en-us/todo/using-keyboard-shortcuts-in-microsoft-to-do)).
- **TickTick — панель деталей справа (десктоп) и экран деталей (телефон).** В справке правка названия отдельно не описана; все правки идут «in the task detail area» ([TickTick, Task Details](https://help.ticktick.com/articles/7055782408586526720)). Клик по строке на вебе ставит курсор в название прямо в строке **[доверие: низкое: наблюдение, в справке нет]**.

**Выход из правки.** Где описано: Enter/`Cmd+Enter` сохраняет, Esc закрывает (Todoist, Things). Нигде в справке не сказано, что Esc откатывает уже набранный текст: у Todoist и Things правки в task view/карточке сохраняются по мере ввода **[доверие: среднее: следует из того, что у них нет кнопки «Сохранить» в task view]**.

## 2. Смена срока у готовой задачи

**Паттерн один у всех: отдельный поповер срока, открываемый одной клавишей или одним жестом, с быстрыми вариантами сверху, текстовым полем и календарём.** Быстрый путь — 2 действия.

- **Todoist.** Веб: «Hover your cursor over the task. Click the scheduler icon and pick a new date.» — 2 клика без открытия задачи. Варианты: Today, Tomorrow, Next week, This weekend и календарь; в поле планировщика можно напечатать «tomorrow at 4pm», «next Friday», «in 5 days» и нажать Enter ([Todoist, Schedule a date and time](https://www.todoist.com/help/articles/introduction-to-dates-and-time-q7VobO)). Клавиши: `T` — «Set date», `Shift+T` — «Remove date» ([shortcuts](https://www.todoist.com/help/articles/use-keyboard-shortcuts-in-todoist-Wyovn2)). Телефон: свайп влево/вправо настраивается на «Schedule» ([Todoist, How to change your swipe actions](https://www.todoist.com/help/todoist/features/how-to-change-your-swipe-actions-D5DQOQz6)) — свайп → вариант, 2 жеста; без свайпа — задача → Date → вариант, 3 тапа. У просроченных есть кнопка «Reschedule».
- **TickTick.** «Right-click a task and choose Date to set it as Today, Tomorrow, Next Week, or a custom date. Or, click Due Date in the task detail area» ([TickTick, Task Details](https://help.ticktick.com/articles/7055782408586526720)) — 3 клика. Телефон: «Swipe the task to the left to see three options… "Move Task", "Delete Task", and "Modify Date"» ([TickTick, List View](https://help.ticktick.com/articles/7055782365863346176)) — свайп → Modify Date → вариант, 3 тапа. Пакетно: «Ctrl + 0 to set all selected tasks to today» ([TickTick, Desktop Interaction Tips](https://help.ticktick.com/articles/7351523697951244288)).
- **Things.** «Hit the date assignment inside the task if it's already scheduled. Or select a to-do and use ⌘ Cmd S» ([Things, Scheduling To-Dos](https://culturedcode.com/things/support/articles/2803579/)). В поповере When: Today, This Evening, календарь, Someday и ввод текста «tues 8am» + Return ([Things, Using Natural Language Input](https://culturedcode.com/things/support/articles/9780167/)). Отдельные клавиши на частые варианты без поповера: `Cmd+T` Today, `Cmd+E` This Evening, `Cmd+O` Someday, `Ctrl+]`/`Ctrl+[` — старт ±1 день, `Ctrl+Shift+]` — ±1 неделя, `Shift+Cmd+D` — дедлайн, `Ctrl+.`/`Ctrl+,` — дедлайн ±1 день ([shortcuts](https://culturedcode.com/things/support/articles/2785159/)). iPhone: «Swipe right to access the "When" feature»; «Pull down in the date picker to use natural language input» ([Things, Using Gestures](https://culturedcode.com/things/support/articles/2803582/)).
- **Microsoft To Do.** Детали задачи → «Add due date» → «Today, Tomorrow, Next week, or Pick a date» ([Microsoft, Add due dates and reminders](https://support.microsoft.com/en-us/todo/add-due-dates-and-reminders-in-microsoft-to-do)) — 3 клика. Контекстное меню по ПКМ (Windows, при включённых context menus) содержит «Due today», «Due tomorrow», «Pick a date», «Remove due date» **[доверие: среднее: то, что контекстные меню включаются в Settings, подтверждает статья Microsoft о задачах; состав пунктов — из вторичного источника и памяти]**.
- **Linear.** «Use the shortcut Shift D when viewing or selecting an issue to set the due date» ([Linear, Issue properties → Due date](https://linear.app/docs/due-dates)). Действие работает над выбранной или наведённой задачей, из списка, без открытия: «Highlighting or selecting one issue both allow you to take actions on the issue using keyboard shortcuts, the command menu, or right-click» ([Linear, Select issues](https://linear.app/docs/select-issues)). Поле даты понимает «"tomorrow", "on Friday", "in 3 hours", "next week", "6pm", "Jun 5"» ([Linear changelog, Issue Reminders](https://linear.app/changelog/2023-01-31-issue-reminders); там это описано для напоминаний и snooze, что тот же пикер у due date — **[доверие: среднее]**).

## 3. Добавление задачи со сроком

**Два механизма, у большинства оба: разбор срока из текста в поле добавления и кнопка срока рядом с полем. Things и Linear разбирают дату только в поле срока, не в названии.**

- **Todoist.** «Press the keyboard shortcut Q or click the "Add task" button to open Quick Add». Под полем по мере ввода появляются «task actions» (Date, Priority, …) ([Todoist, Quick Add](https://www.todoist.com/help/articles/use-task-quick-add-in-todoist-va4Lhpzz)). «Add task» есть и внизу каждого списка/секции, клавиши `A`/`Shift+A` — добавить в конец/начало списка, `Enter` сохраняет и открывает следующее поле ([shortcuts](https://www.todoist.com/help/articles/use-keyboard-shortcuts-in-todoist-Wyovn2)). Путь с разбором: `Q` → «Pay rent tomorrow» → Enter = **3 действия**. Путь кнопкой: `Q` → текст → Date → Tomorrow → Enter = **5**.
- **TickTick.** Десктоп: «Enter the content in the "task addition bar" at the top of the task list page, and press the Enter key». Телефон: «Click the "+" icon that is visible everywhere… You can also set the "date", "priority", "tag"», тулбар над клавиатурой настраивается ([TickTick, Add Tasks](https://help.ticktick.com/articles/7055782422935240704)). В матрице: «Drag the plus sign to any matrix to add a task… tasks created in the "Urgent & Important" matrix will be automatically set to today and high priority» ([TickTick, How to Use Eisenhower Matrix](https://help.ticktick.com/articles/7055782055577124864)). «Task Default» задаёт срок по умолчанию для новых задач.
- **Things.** `Space` — «New to-do below selection», `Cmd+N` — новая задача, Quick Entry — `Ctrl+Space` ([shortcuts](https://culturedcode.com/things/support/articles/2785159/)). Срок при создании — тем же `Cmd+S`/`Cmd+T` в раскрытой новой задаче: `Space` → название → `Cmd+T` → `Cmd+Return` = **4 действия**. В название дата не разбирается: разбор живёт только в поповере When ([Natural Language Input](https://culturedcode.com/things/support/articles/9780167/)).
- **Microsoft To Do.** «You can create a task from the +Add a task input field in any of your lists… type the task's title, and then select Return or Enter» ([Microsoft, Create, edit…](https://support.microsoft.com/en-us/todo/create-edit-delete-and-restore-tasks)). Разбор: «type the due date using natural language like "tomorrow", "Apr 27", and "Friday"» ([Microsoft, Smart due date recognition](https://support.microsoft.com/en-us/todo/smart-due-date-reminder-recognition-in-microsoft-to-do)). Клик по полю → «Pay rent tomorrow» → Enter = **3**.
- **Linear.** `C` открывает модальное окно создания со свойствами; срок — через меню «…» окна: «During issue creation, select the three dot menu to bring up the set due date option» ([Linear, Due dates](https://linear.app/docs/due-dates)). `C` → заголовок → «…» → Due date → вариант → `Cmd+Enter` = **6**. На доске «Create issue by clicking the + sign at the top of a column to create an issue in that column» — колонка заранее задаёт статус ([Linear, Board layout](https://linear.app/docs/board-layout)).

### Как избегают ложных срабатываний разбора

У всех трёх, кто разбирает дату в названии, одинаковая тройка:

1. **Видимая подсветка** распознанного куска прямо в поле: Todoist — «highlights recognized dates», MS To Do — «highlights the words by underlining them», TickTick — «recognized time» отмечена в поле.
2. **Отмена для одной задачи одним действием:** Todoist — «Click the highlighted word… or press Delete or Backspace after Todoist highlights the word» ([Todoist, Smart date recognition](https://www.todoist.com/help/articles/turn-smart-date-recognition-on-or-off-63WfIr)); на телефоне — тап по слову. MS To Do — «press backspace on the highlighted text… the word will become part of your task title». TickTick — «press the "Delete" key… or click on the "recognized time" to cancel recognition».
3. **Глобальный выключатель** в настройках: Todoist «Smart date recognition», MS To Do «Recognize dates and times in task titles» плюс отдельный «Remove dates and times from task titles once recognized», TickTick «Smart Date Parsing» и выбор, убирать ли дату из текста.

Todoist прямо признаёт проблему: «The smart Quick Add might recognize part of your task name as a date, like 'monthly' in 'Create monthly report.'» Разбор у всех завязан на язык: MS To Do на Windows — только английский; Things поддерживает 8 языков, включая русский, но только в поле срока.

## 5. Плавающая кнопка «добавить»

- **Телефон: плавающая «+» есть у трёх из пяти, и у всех она умнее обычного FAB — её перетаскивают на место вставки.** Todoist: «Touch and drag the Dynamic Add Button to where you want to create the new task»; в календаре — на нужный день ([Todoist, Dynamic Add](https://www.todoist.com/help/articles/use-the-dynamic-add-button-in-todoist-ysybl2M1)). Things: «drag the Magic Plus button to insert a to-do at the right place… or add a new to-do to the right day in Upcoming» ([Things for OS 26](https://culturedcode.com/things/blog/2025/09/things-for-os-26/)). TickTick: «Drag the plus sign to any matrix to add a task» — ближайший к нам пример: перетаскивание «+» в квадрант задаёт его свойства.
- **Десктоп/веб: плавающей кнопки нет ни у кого.** Вместо неё: поле или строка «Add task» в каждом списке/секции (Todoist, TickTick, MS To Do), «+» в шапке колонки доски (Linear), кнопка в шапке/сайдбаре («Create new issue», «Add task») и глобальная клавиша (`Q`, `C`, `Cmd+N`, `Ctrl+N`).
- **Linear Mobile и MS To Do на телефоне:** в официальных материалах способ создания не описан (changelog Linear Mobile говорит только «file issues on the go», [Introducing Linear Mobile](https://linear.app/changelog/2024-09-19-introducing-linear-mobile)) **[доверие: низкое — не проверено]**.

## Что применимо к нам

Наш контекст: матрица 2×2 и List view, веб на телефоне и десктопе, у выбранной задачи есть панель действий, inline-поле квадранта принимает только текст, срок — чипами No deadline / Today / Tomorrow / This weekend / Next week и нативными полями, планка ux-r4 (у каждого действия клавиша, axe, чек-лист).

1. **Кнопка срока в панели действий (тикет 03) — стандартный паттерн.** Все пять приложений дают поповер срока из выбранной задачи за 1 клавишу или 1 клик/жест, с быстрыми вариантами сверху. Наши чипы из `DeadlineFields` уже совпадают с набором Todoist (Today, Tomorrow, This weekend, Next week). Цель — **2 действия** от выбранной задачи: «Deadline» → чип, с сохранением сразу по выбору чипа, без кнопки «Сохранить». Клавиша — одна буква; `T` (Todoist) или `D` (по мотивам Linear `Shift+D`) — надо сверить с занятыми у нас `1–4`, `C`, `E`, `N`, Space.
2. **Текст на месте (тикет 02) — ближе всего Things и Linear:** вход по `Enter`/`E` или клику по уже выбранной задаче, `Enter` сохраняет, `Esc` выходит. Ни у кого нет отдельного модального диалога ради названия. Для нас важнее решить, откатывает ли Esc набранное: у лидеров правка в карточке сохраняется, но у них нет строки-карточки в тесной ячейке матрицы, так что откат по Esc у нас безопаснее и привычнее для inline-полей.
3. **Добавление со сроком (тикет 04): кнопка срока рядом с inline-полем обязательна, разбор из текста — опционален.** У Todoist, TickTick и MS To Do есть оба пути, у Things и Linear — только отдельное поле срока. Если делать разбор, то только с тройкой защит: подсветка распознанного, отмена Backspace/кликом, выключатель в настройках. Разбор завязан на язык и даёт ложные срабатывания («monthly»); для первой версии дешевле кнопка срока тем же поповером, что в панели: «+» → текст → Срок → чип → Enter = 5 действий, без срока — 3.
4. **Квадрант как «колонка» доски.** Linear «+» в шапке колонки и TickTick «перетащи + в квадрант» подтверждают наш inline-«+» квадранта как основной путь добавления: квадрант задаётся местом, а не полем формы.
5. **Плавающую кнопку на десктопе можно убирать (тикет 05):** ни одно приложение не держит FAB на вебе, везде вместо неё строка добавления в каждом списке и глобальная клавиша. На телефоне плавающая «+» есть у Todoist, Things, TickTick, но как «перетащи на место»; нам ближе всего TickTick: FAB, который кладёт задачу в квадрант, куда его отпустили. Простую FAB, открывающую полную форму, не держит никто из пятёрки.
6. **Полная форма остаётся у всех, но вторичной:** task view (Todoist), панель деталей (TickTick, MS To Do), раскрытая карточка (Things), модальное окно (Linear). Диалог Edit у нас можно оставить как «все поля сразу», если быстрые пути покрывают текст и срок.
7. **Клавиши «без поповера»** (`Cmd+T` Today и `Ctrl+]` +1 день у Things, `Shift+T` убрать у Todoist) — приятный бонус для постоянного пользователя, но это уже вторая очередь после кнопки срока.

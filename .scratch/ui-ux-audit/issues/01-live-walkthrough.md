Type: task
Status: resolved

## Question

Какие UX-проблемы видны при реальном использовании, а не при чтении кода? Запустить `npm run dev` и пройти в браузере сценарии новичка в двух viewport'ах, desktop (1440×900) и mobile (390×844, touch):

1. Первый визит: welcome-модалка, пустая матрица, первая задача.
2. Добавление задачи: FAB, клавиши 1–4, клик по пустому квадранту, вставка между задачами.
3. Перемещение: drag между квадрантами и внутри квадранта, на mobile через long-press.
4. Изменение, завершение и удаление задачи, восстановление из Completed, «delete all».
5. Дедлайн: пресеты, дата и время, отображение просроченной задачи.
6. Переключение на List view и сортировка; Analytics; тема.
7. Меню аккаунта (без входа): понятно ли, где хранятся задачи.

Результат: каталог находок в `.scratch/ui-ux-audit/walkthrough.md`. На каждую находку: сценарий, viewport, что ожидалось и что произошло, скриншот. Серьёзность пока не ставить. Находки из кода, которые проход подтвердил или опроверг, отметить.

## Answer

Каталог: [walkthrough.md](../walkthrough.md), скриншоты в `walkthrough/`. Главное:

- **Два бага, которые портят данные** (не UX-решения, чинить отдельно и сразу): B1 — правка любой задачи, созданной через UI, молча переносит её в Eliminate; B2 — после перезагрузки редактирование задачи с дедлайном падает (локальные даты не превращаются обратно в `Date`).
- **Mobile:** матрица не показывает ни одной задачи, только счётчики и Expand; в режиме Expand вёрстка ломается; FAB перекрывает действия карточки.
- **Три словаря названий квадрантов:** Do First… (матрица, toast), «Urgent & Important» (форма), «URGENT & IMPORTANT» (Analytics).
- **Обнаружимость:** пустой квадрант не подсказывает, что по нему можно кликнуть; действия только по hover; скрытый скроллбар обрезает задачи; зоны вставки не видны; кнопка аккаунта «G» ничего не объясняет.
- **Непоследовательность:** удаление через нативный `confirm`, у перемещения drag'ом нет Undo, остальное — toast с Undo.
- **Мелочи формы:** ошибка валидации на пустой форме, курсор в начале текста при редактировании, дата создания — самая заметная метаданная карточки.
- **A11y:** кнопка темы без имени, аккаунт не кнопка, вложенные интерактивные элементы в карточке, модалки без `dialog`, кнопки с `opacity-0` недоступны без мыши.
- **Светлая тема:** белый «Expand» на жёлтом и зелёном нечитаем.

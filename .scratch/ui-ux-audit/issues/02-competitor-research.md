# Как другие Eisenhower-приложения решают мобильную матрицу и онбординг

Type: research
Status: resolved

## Question

Как популярные Eisenhower-приложения (eisenhower.me, Focus Matrix, Priority Matrix, Eisenhower-режимы TickTick и Todoist) решают:

- отображение матрицы 2×2 на узком экране: сетка, вкладки, список с группами, раскрытие квадранта;
- перемещение задачи между квадрантами на touch: drag, меню «Move to», свайп;
- онбординг первого визита: модалка, пустое состояние с подсказками, демо-задачи;
- быстрое добавление задачи в конкретный квадрант.

Результат: сводка паттернов с источниками и примечание, какие из них применимы к нашему случаю (анонимный новичок, веб без установки).

## Answer

- Задачи за кнопкой «Expand» не прячет никто. Используют два подхода: полная сетка 2×2 на всю высоту экрана, у каждой ячейки свой скролл, задачи видны сразу (TickTick, Focus Matrix, Glento), или один квадрант на экран с закреплённой мини-матрицей 2×2 со счётчиками (eisenhower.me: iOS и веб, в вебе сетка 2×2 только с `lg`).
- Todoist отдельного вида-матрицы не имеет: предлагает 4 фильтра по лейблам или приоритетам. Нам не подходит, теряется визуальная матрица.
- Перемещение на touch у всех, у кого есть матрица, работает через long-press и drag. У eisenhower.me табы мини-матрицы служат drop-зонами. Есть и альтернатива drag: меню «переместить в квадрант» (eisenhower.me web, Priority Matrix «Move Item…»).
- Свайп используют для действий над задачей (выполнить, таймер), а не для смены квадранта.
- Быстрое добавление: «+» в контексте квадранта (eisenhower.me, «+» в заголовке секции у Focus Matrix, тап по пустому месту у Priority Matrix), выбор квадранта чипами в форме с кнопкой «сохранить и следующую» (eisenhower.me), перетаскивание FAB на квадрант (TickTick), синтаксис `p1`/`%label` (Todoist).
- Приветственной модалки с текстом ни у кого не нашлось. Онбординг устроен так: подписи квадрантов действиями, подзаголовок, кнопка ⓘ со ссылкой на туториал, отдельные тексты пустого состояния квадранта (eisenhower.me), секция «Unsorted» (Focus Matrix).
- Подтверждения, что конкуренты создают демо-задачи при первом запуске, нет. Для нас это гипотеза.
- Среди изученных нет веб-матрицы без регистрации: eisenhower.me web редиректит анонима на `/sign-in`, Priority Matrix требует аккаунт, Focus Matrix и Glento надо устанавливать. Работу без регистрации стоит прямо подавать в онбординге как главное преимущество.
- Ограничения: конкурентов не запускали вживую, источники — help-страницы, App Store и JS-бандл app.eisenhower.me. Раскладка Priority Matrix на iPhone и первый запуск TickTick не задокументированы.

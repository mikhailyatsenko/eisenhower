# Обнаружимость действий над задачей

Type: prototype
Status: resolved
Blocked by: 01

## Question

Как сделать действия над задачей очевидными, не зашумив карточку? Сейчас:

- кнопки complete, edit и delete на desktop видны только при наведении;
- вставку между задачами даёт полоска `InsertTaskZone` высотой 2px;
- о клавишах 1–4 знают только welcome-модалка и футер;
- нет клавиатурных действий над выбранной задачей;
- клик по пустому квадранту открывает форму, по непустому нет.

Прототип: 2–3 варианта карточки и способов добавления, чтобы сравнить.

Дополнено после живого прохода: пустой квадрант показывает только огромное «0 tasks» без подсказки; скрытый скроллбар обрезает задачи без намёка; самая заметная метаданная карточки — дата создания; у перемещения drag'ом нет Undo; FAB на mobile перекрывает действия карточки. Research: меню «Переместить в» как альтернатива drag, «+» в контексте квадранта.

Дополнено из [Мобильная матрица](06-mobile-matrix.md): на mobile теперь компактные карточки (вариант A) без места под три иконки. Нужно решить, что делает тап по карточке (открыть правку? action sheet с Complete / Edit / Move to / Delete?). Long-press drag остаётся основным способом перемещения, «Переместить в» — запасной путь.

## Answer

Прототип: ветка `prototype/task-actions` (`95da8c4`), на главной `?variant=current|A|B|C`. Скриншоты: `walkthrough/proto-05-C-desktop.png`, `proto-05-A-mobile-sheet.png`, `proto-05-B-mobile.png`, `proto-05-B-desktop-add.png`.

**Выбран вариант B — «выбери, потом действуй».** Действия живут не на карточке, а в панели выделенной задачи.

**Карточка.** Только текст и относительный бейдж дедлайна. Ни иконок, ни даты создания. Карточка — один интерактивный элемент.

**Выделение и панель действий.**
- Клик или тап по карточке выделяет её (кольцо), повторный клик, клик по пустому месту или Esc снимает выделение.
- При выделении снизу появляется панель с подписанными кнопками: **Complete**, **Edit**, **Move to** (четыре квадранта по названию, текущий неактивен), **Delete**. На desktop рядом с каждой кнопкой — её клавиша.
- На телефоне это нижняя панель: Complete / Edit / Delete в ряд и «Move to» мини-матрицей 2×2 с крупными кнопками. Матрица над панелью остаётся видна, можно тапнуть другую задачу. Пока панель открыта, FAB скрыт (закрывает находку P4).
- Edit открывает обычную форму правки. Инлайн-редактор в прототипе — только ради скорости.
- Все действия идут через toast с Undo по решению [Единая модель деструктивных действий](04-destructive-actions.md).
- Long-press drag на телефоне и drag на desktop остаются. Чтобы клик выделял, а не начинал перетаскивание, drag на desktop стартует после сдвига на несколько пикселей (activation distance в dnd-kit).

**Клавиатура.**
- ↑↓ — задача в квадранте, ←→ — соседний квадрант; первое нажатие ↓ выделяет первую задачу.
- `C` / Space — завершить, `E` / Enter — правка, `1–4` — перенести, `Del` / Backspace — удалить, Esc — снять выделение, `N` — добавить в текущий квадрант.
- **`1–4` зависят от контекста:** без выделения открывают форму добавления в квадрант (как сейчас), с выделением переносят задачу. Двойной смысл клавиш — осознанный компромисс: подсказки в панели показывают, что 1–4 сейчас сделают.
- `?` открывает шпаргалку. Под матрицей на desktop строка-подсказка «Click a task to select it · ↑↓←→ move selection · ? all shortcuts».

**Добавление.**
- Клик по пустому месту **любого** квадранта (не только пустого) открывает инлайн-поле в конце списка; Enter добавляет и оставляет поле открытым для следующей задачи, Esc закрывает. Плюс «+» в заголовке квадранта и `N`.
- В заголовке на широких экранах подсказка «click empty space to add», в пустом квадранте — «Click to add a task» / «Tap to add» вместо огромного «0 tasks».
- **`InsertTaskZone` убирается.** Вставка между задачами = добавить и перетащить.
- У инлайн-поля один индикатор фокуса: пунктирная рамка цвета квадранта становится сплошной, браузерный outline выключен. Наложение двух обводок пользователь заметил в прототипе.

**Почему B.** Карточки в матрице остаются чистыми, особенно компактные на телефоне, где под иконки нет места. Все действия подписаны словами и обнаруживаются одним кликом. Клавиатура получается полной почти бесплатно. A прятал всё за «⋯», и на телефоне его лист закрывал матрицу. C честно всё показывал, но четыре кнопки на каждой карточке зашумляли квадрант (`proto-05-C-desktop.png`), а свайпы в ячейке шириной 170px тесные.

# Спека UX-изменений

Итог карты [UI/UX-аудит](map.md). Это индекс **срезов** в порядке поставки. Каждый срез выпускается сам и не оставляет UI в противоречивом состоянии. Решения здесь не пересказываются: детали — в тикетах по ссылкам, находки (F1, M3, …) — в [каталоге прохода](walkthrough.md). Как составлен порядок — в [Шкала серьёзности и порядок в спеке](issues/18-severity-prioritization.md).

## Серьёзность

Критерии проверяются по порядку, срез получает уровень самой тяжёлой закрываемой находки.

- **S1 Critical** — новичок не может пройти основной сценарий (добавить, переместить, изменить, завершить, удалить) или теряет данные.
- **S2 Major** — сценарий проходится, но путает, мешает или нарушает WCAG 2.2 AA.
- **S3 Minor** — полировка.

Mobile и desktop на уровень не влияют. Внутри уровня: сначала новичок, потом вошедший; S1 вошедшего идёт раньше S2 новичка.

Два неочевидных ребра: **E раньше F** — все действия панели идут через Undo, иначе `window.confirm` пришлось бы тянуть в новый UI; **K после J** — Migration очищает локальную копию только после подтверждения сервером.

Ниже у срезов — только специфичные критерии.

## R1 «Новичок справляется»

### A. Инфраструктура a11y
- **Что:** `jest-axe` в существующем jest; ручной чек-лист (основные сценарии только клавиатурой, затем VoiceOver на macOS и iOS) в репозитории.
- **Решения:** [Минимальная планка доступности](issues/11-accessibility-baseline.md).
- **a11y:** это и есть инструмент проверки остальных срезов.

### B. Единые названия квадрантов
- **Что:** один источник названий и критериев вместо `QUADRANT_TITLES` + UI-строк в enum `MatrixQuadrants`; форма показывает название и подзаголовок-критерии, toast — только название.
- **Решения:** [Единый словарь названий квадрантов](issues/09-quadrant-vocabulary.md).
- **Закрывает:** A2, N1.

### C. Убрать Analytics, подписать кнопку аккаунта
- **Что:** Analytics целиком, кнопка в шапке, Alt+S. Временно, до среза L: у кнопки аккаунта видимая подпись «Sign in» и доступное имя.
- **Решения:** [Что Analytics даёт новичку](issues/13-analytics-value.md), [Шапка и навигация](issues/07-header-navigation.md).
- **Закрывает:** N1, N2; частично F4, X1.

### D. Онбординг вне матрицы
- **Что:** убрать welcome-модалку (автопоказ, `dontShowPopup`); серверный `h1` на главной; страница `/eisenhower-matrix` (в `sitemap.ts`, свои title/description, совет о балансе квадрантов) со ссылкой из футера.
- **Решения:** [Онбординг первого визита](issues/08-first-visit-onboarding.md).
- **Закрывает:** F1, F2.

### E. Новый toast и Undo вместо confirm
- **Что:** один toast за раз, снизу, 6 с с паузами, без крестика, `Ctrl/Cmd+Z`; toast только на Complete / Delete / Move (добавление и правка молча); Delete без `window.confirm`, Move (drag) с Undo; error-toast убирается.
- **Решения:** [Поведение toast-уведомлений](issues/12-toast-behaviour.md), [Единая модель деструктивных действий](issues/04-destructive-actions.md).
- **Закрывает:** C2, M6.
- **a11y:** контейнер `role="status"`, Undo доступен по Tab сразу после матрицы.

### F. Выделение и панель действий
- **Что:** карточка — только текст и дедлайн, один интерактивный элемент; клик/тап выделяет, панель Complete / Edit / Move to / Delete; клавиатура (↑↓←→, C, E, 1–4 по контексту, Del, Esc, N, `?`-шпаргалка); drag стартует после сдвига; `KeyboardSensor` убирается.
- **Решения:** [Обнаружимость действий над задачей](issues/05-task-actions-discoverability.md).
- **Закрывает:** M3, X2, X3, X5, M1.
- **a11y:** квадрант — `listbox`, задача — `option` с `aria-selected`; матрица — одна остановка Tab, roving tabindex; фокус = выделение; после действия фокус на соседнюю задачу, после Undo — на восстановленную; панель `role="toolbar"`; форма правки и шпаргалка на нативном `<dialog>`, фокус возвращается на источник.

### H. Мобильная матрица и «+N» на всех ширинах
- **Что:** < 640px — сетка 2×2 на всю высоту, без Expand, компактные карточки, тап по заголовку — полноэкранный квадрант, нижняя панель с Move to мини-матрицей, FAB скрыт при панели. На всех ширинах `scrollbar-hidden` уходит и появляется индикатор «+N ниже».
- **Решения:** [Мобильная матрица](issues/06-mobile-matrix.md).
- **Закрывает:** P1, P2, P3, P4, M2, T1 (Expand).
- **a11y:** цели 44×44 у панели и мини-матрицы.

### P. Мелкие правки
- **A1:** ошибка валидации в форме показывается только после первого blur или submit.
- **M5:** цель drag подсвечивается рамкой цвета квадранта вместо заливки `bg-gray-400`.
- Решений в карте не требуют, см. [тикет 18](issues/18-severity-prioritization.md).

## R2 «Вошедший не теряет правки»

### J. Офлайн-ядро облачной матрицы
- **Что:** `persistentLocalCache` + `persistentMultipleTabManager`; чтение живой подпиской `onSnapshot`; стор не ждёт промисов записи; полоса под шапкой: нейтральная «You're offline…» / «Syncing…» / «All changes saved», красная только при отказе сервера («Reload» / «Sign in again»); `beforeunload` при неотправленных правках; предупреждение при выходе и очистка кэша; холодный старт без кэша — сообщение вместо пустой матрицы.
- **Решения:** [Офлайн для вошедшего пользователя](issues/17-offline-ux.md), [Как ведёт себя облачная матрица без сети](issues/16-firestore-offline-research.md).
- **Закрывает:** потерю очереди записей при перезагрузке, подмену матрицы ошибкой.
- **a11y:** нейтральная полоса `role="status"`, красная `role="alert"`, объявляется один раз, фокус не перехватывает.

## R3 «Всё понятно без объяснений»

### G. Добавление кликом по пустому месту
- **Что:** клик по пустому месту любого квадранта открывает инлайн-поле, Enter оставляет его открытым; «+» в заголовке; `InsertTaskZone` уходит.
- **Решения:** [Обнаружимость действий над задачей](issues/05-task-actions-discoverability.md).
- **Закрывает:** M4, F3 (частично).
- **a11y:** имя поля «Add task to <квадрант>»; в пустом квадранте фокус на кнопке «Add a task»; один индикатор фокуса.

### I. Подсказки внутри матрицы
- **Что:** пример + CTA в пустом квадранте; «click empty space to add» до первого использования; строка «select» под матрицей (мышь/touch по указателю); «No sign-up — … How it works →» над пустой матрицей; ссылка на `/eisenhower-matrix` из шпаргалки `?`.
- **Решения:** [Онбординг первого визита](issues/08-first-visit-onboarding.md).
- **Закрывает:** F3, A3.

### K. Одна матрица и Migration
- **Что:** при входе задачи переносятся (toast Migration с Undo; при непустом облаке — один вопрос), локальная копия очищается после `waitForPendingWrites`; убираются Local/Cloud, `SwitchTaskSource`, `?cloud`, «Copy to Cloud»; после выхода — пустая матрица с подсказкой.
- **Решения:** [Модель «одна матрица»](issues/03-one-matrix-model.md).
- **a11y:** вопрос при входе — нативный `<dialog>`.

### L. Шапка и навигация
- **Что:** шапка во всю ширину: логотип (название от `md`), сегменты Matrix | List, тема, «Sign in» (от `lg` — «Saved only on this device») или аватар с меню (имя, email, место хранения, Sign out); полоса статуса из J — часть шапки; градиент и угловые иконки уходят.
- **Решения:** [Шапка и навигация](issues/07-header-navigation.md).
- **Закрывает:** F4, X1, P5, T1 (аккаунт).
- **a11y:** сегменты `tablist`/`tab`; меню по паттерну WAI-ARIA menu button; у кнопки темы `aria-label`.

## R4 «Полировка»

### M. Дедлайны и просрочка
- **Что:** на карточке абсолютная дата в локали браузера и бейдж OVERDUE / DUE TODAY / DUE SOON вместо красного кольца; в форме чипы и нативные `date`/`time`, `react-datepicker` уходит; в модели `Task` признак «время задано»; дедлайн без времени — до конца дня.
- **Решения:** [Дедлайны и просрочка](issues/15-deadlines-overdue.md).
- **a11y:** статус читается текстом; у поля дедлайна видимый `<label>`.

### N. List view по секциям
- **Что:** секции в порядке приоритета с липкими заголовками и значком 2×2, сворачивание запоминается; порядок как в матрице, сортировки уходят; выделение, панель и клавиши как в матрице, без drag; текст по левому краю; скролл наверх при переключении; выбранный вид запоминается.
- **Решения:** [Роль List view](issues/10-list-view-role.md).
- **Закрывает:** L1, L2, L3, L4.
- **a11y:** секция — `listbox`; список — одна остановка Tab.

### O. Completed как секция List view
- **Что:** последняя свёрнутая секция, из Matrix — строка «✓ N completed →»; новые сверху, 50 и «Show more»; выделение и панель Restore / Delete с Undo; Restore в начало исходного квадранта с toast; «Delete all» — модальный диалог; только дата завершения.
- **Решения:** [Блок Completed](issues/14-completed-section.md).
- **Закрывает:** C3, C4, M7.
- **a11y:** исходный квадрант подписан словом; «Delete all» на нативном `<dialog>`.

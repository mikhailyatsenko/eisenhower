# 11: Выделение и панель действий (мышь и тап)

**What to build:** Карточка в матрице — только текст и дедлайн. Клик или тап выделяет задачу, и снизу появляется панель с подписанными кнопками Complete, Edit, Move to, Delete. Все действия проходят через Undo. Срез F [спеки R1](../spec.md), решения: [Обнаружимость действий над задачей](../../ui-ux-audit/issues/05-task-actions-discoverability.md) (primary source — ветка `prototype/task-actions`, вариант B), [Минимальная планка доступности](../../ui-ux-audit/issues/11-accessibility-baseline.md). Закрывает M3, X2, X5, M1.

**Blocked by:** 10

**Status:** ready-for-agent

- [ ] **Selected Task** — одно состояние в UI-сторе: id задачи или ничего. Одновременно выделена не больше одной задачи.
- [ ] Карточка матрицы: текст и относительный бейдж дедлайна, без иконок, ссылок-действий и даты создания. URL в тексте показываются обычным текстом, без `Linkify`.
- [ ] Квадрант — `listbox` с доступным именем по названию квадранта, задача — `option` с `aria-selected`.
- [ ] Клик или тап выделяет задачу, кольцо выделения контрастнее 3:1 в обеих темах. Повторный клик, клик по пустому месту квадранта или Esc снимают выделение. **Переходное решение до среза G:** клик по пустому месту пустого квадранта по-прежнему открывает форму добавления.
- [ ] Панель — `role="toolbar"` с подписью «Actions for “<текст задачи>”», внизу окна, пока есть выделение. Кнопки Complete, Edit, Move to (четыре квадранта по названию, текущий неактивен), Delete. Появление панели не объявляется.
- [ ] Complete, Delete и Move to идут через слот отмены (тикеты 07 и 09). Edit открывает обычную форму правки. После Complete, Delete и Move выделение переходит на следующую задачу квадранта, если её нет — на предыдущую.
- [ ] Toast стоит прямо над панелью, без панели — у нижнего края.
- [ ] Drag мышью стартует после сдвига на несколько пикселей (activation distance), клик выделяет. Long-press на touch не меняется (300 мс, tolerance 10). `KeyboardSensor` dnd-kit удалён. Блокирование drag через `data-no-dnd` для кнопок карточки убрано.
- [ ] **Переходное решение до среза N:** List view сохраняет карточку с кнопками complete, edit, delete, видимыми всегда, без `opacity-0`. Действия идут через слот отмены. Общие у карточек матрицы и List view только текст и бейдж дедлайна.
- [ ] Axe-исключение X2 снято.
- [ ] Тесты на главном seam: клик выделяет (`aria-selected="true"`) и показывает toolbar с именем; Move to и Complete из панели дают toast и переводят выделение; в карточке матрицы нет вложенных кнопок; List view по-прежнему удаляет и завершает.
- [ ] В ручной чек-лист добавлены выделение и панель.

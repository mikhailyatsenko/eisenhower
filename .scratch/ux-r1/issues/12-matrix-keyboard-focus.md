# 12: Клавиатура матрицы и правила фокуса

**What to build:** Вся работа с матрицей доступна с клавиатуры. В матрицу попадают одной остановкой Tab, стрелками ходят по задачам, одной клавишей завершают, правят, переносят и удаляют. Фокус никогда не теряется. Срез F [спеки R1](../spec.md), решения: [Обнаружимость действий над задачей](../../ui-ux-audit/issues/05-task-actions-discoverability.md) (primary source — `prototype/task-actions`, вариант B), [Минимальная планка доступности](../../ui-ux-audit/issues/11-accessibility-baseline.md). Закрывает X3.

**Blocked by:** 11

**Status:** ready-for-agent

- [ ] Матрица — одна остановка Tab, дальше roving tabindex. Фокус и выделение совпадают. Tab в матрицу выделяет последнюю выделенную задачу, а если её нет — первую в Do First (первую непустую, если Do First пуст).
- [ ] **Переходное решение до среза G:** пустые квадранты в roving tabindex не участвуют. У полностью пустой матрицы нет остановки Tab.
- [ ] Клавиши обрабатываются, только когда фокус не в поле ввода и не в открытом диалоге:

  | Клавиша | Без выделения | С выделением |
  |---|---|---|
  | ↓ / ↑ | ↓ выделяет первую задачу | следующая / предыдущая в квадранте, без зацикливания |
  | ← / → | — | соседний квадрант по сетке 2×2, та же позиция или последняя; пустые пропускаются |
  | `1–4` | открыть форму добавления в квадрант N | Move в квадрант N; в текущий — ничего |
  | `C` / Space | — | Complete |
  | `E` / Enter | — | Edit |
  | Del / Backspace | — | Delete |
  | `N` | добавить в Do First | добавить в квадрант выделения |
  | Esc | — | снять выделение |

- [ ] **Переходное решение до среза G:** «добавить» по `N` и `1–4` открывает существующую форму добавления.
- [ ] Глобальный обработчик `1–4` слит с обработчиком матрицы: клавиша срабатывает один раз.
- [ ] На desktop у кнопок панели `kbd` показывает, что клавиша сделает сейчас: `1–4` — «Move to».
- [ ] Tab с задачи переводит фокус в панель, Esc из панели возвращает на задачу.
- [ ] Фокус после действия: следующая задача квадранта, иначе предыдущая, иначе ближайшая задача соседнего квадранта, иначе контейнер матрицы с `tabindex="-1"`. На `body` фокус не падает. После Undo фокус и выделение на восстановленной задаче.
- [ ] Ядро навигации взято из прототипа (вариант B, сокращено):

  ```ts
  // grid order: 0 1 / 2 3  (Do First, Schedule / Delegate, Eliminate)
  const target = key === 'ArrowRight' ? [1, 1, 3, 3][col] : [0, 0, 2, 2][col];
  const tl = tasks[ORDER[target]];
  if (tl.length) select(tl[Math.min(cur.i, tl.length - 1)]);
  ```

- [ ] Тесты на главном seam: одна остановка Tab; каждая строка таблицы; клавиши не срабатывают в поле формы; фокус после Complete, Delete и Move в последней задаче квадранта и после Undo.
- [ ] В ручной чек-лист добавлен проход только клавиатурой.

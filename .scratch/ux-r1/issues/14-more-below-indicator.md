# 14: Индикатор «+N below» на всех ширинах

**What to build:** Если задачи не влезают в квадрант, внизу видно «+3 below ↓». Клик по индикатору прокручивает список. Задачи больше не обрезаются молча ни на телефоне, ни на desktop. Срез H [спеки R1](../spec.md), решение: [Мобильная матрица](../../ui-ux-audit/issues/06-mobile-matrix.md) (комментарий про все ширины), primary source — `CellList` в `prototype/task-actions`. Закрывает M2.

**Blocked by:** 13

**Status:** ready-for-agent

- [ ] Со списков квадрантов убран `scrollbar-hidden`.
- [ ] Внизу переполненного списка стоит индикатор «+N below ↓», где N — число задач, не видимых целиком ниже края. Индикатор пересчитывается при прокрутке и при изменении числа задач. Логика из прототипа (сокращено):

  ```ts
  const bottom = el.scrollTop + el.clientHeight;
  const hidden = items.filter((li) => li.offsetTop + li.offsetHeight > bottom + 2).length;
  ```

- [ ] Клик по индикатору прокручивает список вниз, при `prefers-reduced-motion` без плавной анимации.
- [ ] У индикатора доступное имя «N more tasks below», контраст текста не меньше 4.5:1.
- [ ] Тест на главном seam: размеры задаются в тесте (jsdom не делает раскладку); проверяется число и исчезновение индикатора после прокрутки.

# 17: Нижняя панель действий на телефоне

**What to build:** На телефоне тап по задаче открывает нижнюю панель во всю ширину: Complete, Edit, Delete в ряд и Move to мини-матрицей 2×2 с крупными кнопками. FAB прячется, toast встаёт над панелью. Срез H [спеки R1](../spec.md), решения: [Обнаружимость действий над задачей](../../ui-ux-audit/issues/05-task-actions-discoverability.md), [Мобильная матрица](../../ui-ux-audit/issues/06-mobile-matrix.md), primary source — `prototype/task-actions`, вариант B (телефон). Закрывает P4.

## Comments

**Итог (ветка `ux-r1`).**
- **Панель** — тот же `ActionToolbar` (`features/selectTask`), раскладка выбирается в JS через `useIsPhone()`, чтобы порядок в DOM совпадал с видимым (VoiceOver читает Complete, Edit, Delete, затем Move to). На < 640px: `fixed inset-x-0 bottom-0`, скругление сверху, нижний отступ с учётом `safe-area-inset-bottom`. Сверху текст задачи в одну строку (`aria-hidden`, он уже в имени toolbar «Actions for “…”»), затем Complete / Edit / Delete сеткой 3 колонки, подпись «Move to» и группа из четырёх кнопок сеткой 2×2 в порядке квадрантов. Кнопка текущего квадранта `disabled`. Все кнопки `min-h-11`, на 320px ширина держится сетками. Классы в `PANEL_STYLES.desktop` / `.phone` (`ActionToolbar/consts`). Desktop не изменился. Цвета в мини-матрице как на desktop (белый текст и цветная точка), без рамок цвета квадранта из прототипа: на тёмной панели светлая тема прототипа не проходит по контрасту.
- **FAB** скрыт при выделенной задаче только на < 640px (`AddTask`). На desktop панель посередине и FAB справа не пересекаются, клавиша `N` работает при любой ширине. В раскрытом квадранте скрыт так же.
- **Toast** встаёт над панелью через существующий `useToastClearance(toolbarRef)`: он меряет верх панели через `ResizeObserver`, так что высокая панель учитывается без нового кода.
- **`useIsPhone`** в `shared/hooks`: `(max-width: 639px)` был строкой в трёх местах, теперь хук используют `useFullScreenQuadrant`, `ActionToolbar` и `AddTask`.
- **Страница `/eisenhower-matrix`:** в разделе 3 подраздел «On a phone» про полноэкранный квадрант, тап, нижнюю панель с Move to и long-press drag.
- **Тесты.** `src/app/tests/mobileActionPanel.test.tsx`, 6 шт. при 375px и coarse: порядок кнопок (ряд, затем мини-матрица) и неактивный текущий квадрант; перенос через мини-матрицу с toast «Moved to Eliminate»; FAB скрыт при выделении и возвращается после снятия; FAB скрыт в раскрытом квадранте; desktop — FAB на месте, тулбар в одну строку; axe с открытой панелью. В `serverPages.test.tsx` проверка подраздела «On a phone». Все 20 наборов jest зелёные (167 тестов), tsc, eslint, prettier чистые.
- **В браузере не проверялось:** chrome-devtools в сессии недоступен. Раскладка, 44×44, toast над панелью, long-press drag и VoiceOver вынесены в чек-лист H, пункты 15–20.
- **Открытый вопрос: панель накрывает нижний ряд.** Высота панели по классам около 240px. Сетка под неё не сжимается (как в прототипе), поэтому на 390×844 закрыта нижняя часть Delegate и Eliminate, а на 320×568 скорее всего почти весь нижний ряд. В раскрытом квадранте последние задачи не докрутить из-под панели, так что пункт чек-листа тикета 16 «панель не закрывает последнюю задачу» сейчас, вероятно, не проходит (формулировка не менялась). Варианты: (1) оставить как есть, задачи под панелью видны после её закрытия; (2) нижний отступ у списков на высоту панели (переменная как у toast), чтобы задачи докручивались над ней; (3) сжимать сетку, пока панель открыта (раскладка прыгает при тапе); (4) сделать панель ниже, например подпись «Move to» в одну строку с мини-матрицей. Решить после взгляда на Vercel preview.

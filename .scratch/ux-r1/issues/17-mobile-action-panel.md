# 17: Нижняя панель действий на телефоне

**What to build:** На телефоне тап по задаче открывает нижнюю панель во всю ширину: Complete, Edit, Delete в ряд и Move to мини-матрицей 2×2 с крупными кнопками. FAB прячется, toast встаёт над панелью. Срез H [спеки R1](../spec.md), решения: [Обнаружимость действий над задачей](../../ui-ux-audit/issues/05-task-actions-discoverability.md), [Мобильная матрица](../../ui-ux-audit/issues/06-mobile-matrix.md), primary source — `prototype/task-actions`, вариант B (телефон). Закрывает P4.

**Blocked by:** 15

**Status:** ready-for-agent

- [ ] На ширине < 640px панель выделенной задачи — нижняя панель во всю ширину. Complete, Edit, Delete в ряд. Под ними Move to — мини-матрица 2×2 с кнопками по названию квадранта, текущий квадрант неактивен.
- [ ] Все кнопки панели и мини-матрицы не меньше 44×44.
- [ ] Матрица над панелью видна, тап по другой задаче переключает выделение.
- [ ] Пока панель открыта, FAB «New task» скрыт.
- [ ] Toast стоит над панелью и не перекрывает её.
- [ ] Long-press drag работает как раньше.
- [ ] Раздел 3 страницы `/eisenhower-matrix` дописан про телефон: тап, нижняя панель, long-press drag.
- [ ] Тест на главном seam при узкой ширине: мини-матрица Move to с неактивным текущим квадрантом, FAB скрыт при выделении и виден без него.
- [ ] В ручной чек-лист добавлен проход VoiceOver на iOS по панели.

# 02: Действия не ждут облака и пишут только изменённое

**What to build:** Вошедший пользователь без сети добавляет, меняет, переносит, завершает, восстанавливает и удаляет задачи так же, как при сети. Форма добавления закрывается сразу, повторный Enter не создаёт дубль. Правки переживают перезагрузку и сами уходят в облако, когда сеть вернётся. Правка на одном устройстве не затирает чужие задачи. Срез J1 [спеки R2](../spec.md), замечания для реализации из [Офлайн для вошедшего пользователя](../../ui-ux-audit/issues/17-offline-ux.md).

**Status:** resolved

## Comments

- Чистые функции в `tasksStore/lib`: `actionChanges` (изменённые задачи и соседи по затронутым квадрантам, у которых индекс расходится с `order` на сервере) и `reorderedQuadrants` (какие квадранты поменял drag). Табличные тесты рядом. `wholeMatrixChanges` удалена. Разбор «документ ↔ `Task`» уже покрыт таблицей из 01.
- В Completed пишется только изменённая задача: снимок сортирует его по `completedAt`, а `order` там не читается. Иначе каждое Complete переписывало бы весь Completed.
- После записи стор сразу получает записанные `order`, не дожидаясь снимка. Настоящий Firestore присылает локальный снимок асинхронно, и без этого быстрое следующее действие (Undo) сравнивало бы индексы со старыми `order`.
- Известное ограничение, принятое спекой («последняя запись выигрывает»): сосед в том же квадранте пишется полным `set`, а не одним `order`. Поэтому устаревшая вкладка без сети может вернуть ему старый текст или воскресить удалённую на другом устройстве задачу, если сдвинула его порядок. `update` одного `order` отклонил бы весь батч при удалённом документе. Если это станет заметно, понадобится `TaskChange` вида `order`.
- Модель синхронизации: `src/shared/stores/syncStore` (`trackCloudWriteAction`, `hasPendingWrites` из последнего снимка, `unconfirmedWrites` этой сессии, `selectHasPendingChanges`). Сбрасывается при отписке. Отказ записи уходит в `console.error`.
- Тесты главного seam: `src/app/tests/offlineWrites.test.tsx`. Ручной чек-лист: раздел J, «Правки без сети». С настоящим Firestore в этой сессии не проверялся.

# 03: Выход из аккаунта стирает кэш на устройстве

**What to build:** После выхода из аккаунта задачи вошедшего пользователя не остаются на устройстве: кэш облачной матрицы в IndexedDB стирается всегда, без вопроса «доверяете ли устройству». Без этого тикета кэш из 01 оставил бы задачи на диске общего компьютера, поэтому J1 уходит в `main` только вместе с ним. Срез J1 [спеки R2](../spec.md), решение: [Офлайн для вошедшего пользователя](../../ui-ux-audit/issues/17-offline-ux.md), строка «Выход из аккаунта» (без диалога — он в тикете 09).

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] «Sign out» отписывает от облака и вызывает `clearDevice` облачного клиента: `terminate` + `clearIndexedDbPersistence`.
- [ ] После очистки следующий вход работает без перезагрузки: клиент создаёт Firestore заново. Если `firebase@11.4.0` не даёт снова вызвать `initializeFirestore` на том же `app`, страница после выхода перезагружается. Какой вариант выбран, записать в Comments.
- [ ] Если очистка не удалась (другая вкладка держит IndexedDB, `failed-precondition`), ошибка уходит в лог, и очистка повторяется при следующем запуске без вошедшего пользователя. Выход в одной вкладке доходит до всех через подписку на пользователя, и каждая отпускает IndexedDB.
- [ ] Кэш стирается только при выходе по «Sign out». Потерю сессии без «Sign out» обрабатывает тикет 07, и там кэш не стирается.
- [ ] Тесты на главном seam: после «Sign out» фейк отчитывается о стёртом кэше и очереди; `reload()` без входа ничего облачного не показывает; повторный вход снова показывает задачи сервера.
- [ ] Чек-лист: после выхода в DevTools → Application нет базы Firestore; выход при двух открытых вкладках.

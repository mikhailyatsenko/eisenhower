# 05: Холодный старт без сети

**What to build:** Вошедший пользователь, впервые открывший приложение на этом устройстве без сети, видит матрицу с полосой офлайна и строкой «Your tasks are in your account. They'll appear when you're back online.», а не пустую матрицу или долгий лоадер. Добавлять задачи можно. Когда сеть вернётся, задачи из облака появятся сами, а строка исчезнет. Срез J2 [спеки R2](../spec.md), решение: [Офлайн для вошедшего пользователя](../../ui-ux-audit/issues/17-offline-ux.md), строка «Холодный старт без кэша».

**Blocked by:** 04

**Status:** ready-for-agent

- [ ] Первый снимок из кэша (`fromCache`) пустой и есть признак офлайна (`navigator.onLine === false` или 10 с без ответа сервера) — лоадер снимается, показываются матрица, полоса offline и строка над матрицей.
- [ ] Первый пустой снимок из кэша при сети держит лоадер до снимка с сервера. После 10 с без ответа срабатывает правило выше.
- [ ] Строка исчезает с первым снимком с сервера. Задачи, добавленные до этого, остаются и уходят в облако вместе с задачами сервера.
- [ ] Молча пустая матрица вошедшему больше не показывается.
- [ ] Тесты на главном seam: `deviceCache: 'empty'` + `offline` — матрица, полоса и строка; задачу можно добавить; `goOnline` — строки нет, видны задачи сервера и добавленная; `deviceCache: 'empty'` + `stalled` — лоадер, через 10 с строка; axe чист.
- [ ] Чек-лист: чистый профиль браузера, вход, DevTools Offline, перезагрузка.

# 01: Инлайн-поле по клику на пустое место и «+»

**What to build:** Пользователь добавляет задачу прямо в нужный квадрант. Клик по пустому месту любого квадранта или «+» в его заголовке открывает в конце списка поле «Add task to <квадрант>». Enter добавляет задачу и оставляет поле открытым для следующей, Esc закрывает. Еле видные полоски вставки между задачами исчезают. Срез G [спеки R3](../spec.md), решение: [Обнаружимость действий над задачей](../../ui-ux-audit/issues/05-task-actions-discoverability.md), раздел «Добавление». Закрывает M4.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] Пустое место — любая точка квадранта, кроме карточки, кнопок заголовка, «+N below» и самого поля (промежутки между карточками, место под последней задачей, пустой квадрант целиком).
- [ ] Клик по пустому месту без выделения открывает поле в конце списка квадранта; список прокручивается к полю, «+N below» пересчитывается. При выделенной задаче первый клик только снимает выделение, поле не открывается (заменяет переходное решение R1 для пустых квадрантов).
- [ ] «+» в заголовке каждого квадранта — кнопка «Add a task to <квадрант>», открывает поле; вне Tab-порядка (`tabindex="-1"`).
- [ ] Открытие поля снимает выделение, панель действий закрыта, пока поле открыто.
- [ ] Поле одно на странице: открытие в другом квадранте переносит его туда вместе с набранным текстом.
- [ ] Enter добавляет задачу с обрезанным текстом в конец квадранта, очищает поле и оставляет фокус в нём. Задача не выделяется, toast нет. Пустой текст и пробелы Enter игнорирует без ошибки; длина ограничена 200 символами.
- [ ] Esc закрывает поле без добавления; фокус — на то, что его открыло («+» квадранта; после клика по пустому месту — «+» этого квадранта). Уход фокуса закрывает пустое поле, поле с текстом остаётся открытым до Enter или Esc. Фокус никогда не на `body`.
- [ ] Доступное имя поля — «Add task to <квадрант>». Один индикатор фокуса: пунктирная рамка цвета квадранта становится сплошной, браузерный outline выключен; рамка не меньше 3:1 к фону квадранта в обеих темах.
- [ ] `InsertTaskZone` и параметр вставки по индексу удалены. FAB «New task» по-прежнему открывает модальную форму с дедлайном.
- [ ] Вошедший пользователь добавляет через поле без сети, запись не ждёт облака (R2).
- [ ] Тесты на главном seam: клик по пустому месту Schedule → в фокусе `textbox` «Add task to Schedule»; текст + Enter → задача последней в `listbox` Schedule, поле пустое и в фокусе, toast нет; пустой Enter ничего не добавляет; Esc → поля нет, фокус на «+» Schedule; при выделении клик только снимает его; текст переезжает в другой квадрант; «+» открывает поле; `goOffline` → добавление через поле, после `goOnline` задача в `serverTasks()`; axe с открытым полем. Тесты R1, ожидавшие форму по клику в пустом квадранте, обновлены.
- [ ] Чек-лист: основной сценарий «Добавить задачу» переписан под поле; раздел G — клик по промежутку между карточками против начала drag, одна рамка фокуса в обеих темах.

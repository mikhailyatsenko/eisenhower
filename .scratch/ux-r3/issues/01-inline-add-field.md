# 01: Инлайн-поле по клику на пустое место и «+»

**What to build:** Пользователь добавляет задачу прямо в нужный квадрант. Клик по пустому месту любого квадранта или «+» в его заголовке открывает в конце списка поле «Add task to <квадрант>». Enter добавляет задачу и оставляет поле открытым для следующей, Esc закрывает. Еле видные полоски вставки между задачами исчезают. Срез G [спеки R3](../spec.md), решение: [Обнаружимость действий над задачей](../../ui-ux-audit/issues/05-task-actions-discoverability.md), раздел «Добавление». Закрывает M4.

**Blocked by:** None (can start immediately)

**Status:** resolved

- [x] Пустое место — любая точка квадранта, кроме карточки, кнопок заголовка, «+N below» и самого поля (промежутки между карточками, место под последней задачей, пустой квадрант целиком).
- [x] Клик по пустому месту без выделения открывает поле в конце списка квадранта; список прокручивается к полю, «+N below» пересчитывается. При выделенной задаче первый клик только снимает выделение, поле не открывается (заменяет переходное решение R1 для пустых квадрантов).
- [x] «+» в заголовке каждого квадранта — кнопка «Add a task to <квадрант>», открывает поле; вне Tab-порядка (`tabindex="-1"`).
- [x] Открытие поля снимает выделение, панель действий закрыта, пока поле открыто.
- [x] Поле одно на странице: открытие в другом квадранте переносит его туда вместе с набранным текстом.
- [x] Enter добавляет задачу с обрезанным текстом в конец квадранта, очищает поле и оставляет фокус в нём. Задача не выделяется, toast нет. Пустой текст и пробелы Enter игнорирует без ошибки; длина ограничена 200 символами.
- [x] Esc закрывает поле без добавления; фокус — на то, что его открыло («+» квадранта; после клика по пустому месту — «+» этого квадранта). Уход фокуса закрывает пустое поле, поле с текстом остаётся открытым до Enter или Esc. Фокус никогда не на `body`.
- [x] Доступное имя поля — «Add task to <квадрант>». Один индикатор фокуса: пунктирная рамка цвета квадранта становится сплошной, браузерный outline выключен; рамка не меньше 3:1 к фону квадранта в обеих темах.
- [x] `InsertTaskZone` и параметр вставки по индексу удалены. FAB «New task» по-прежнему открывает модальную форму с дедлайном.
- [x] Вошедший пользователь добавляет через поле без сети, запись не ждёт облака (R2).
- [x] Тесты на главном seam: клик по пустому месту Schedule → в фокусе `textbox` «Add task to Schedule»; текст + Enter → задача последней в `listbox` Schedule, поле пустое и в фокусе, toast нет; пустой Enter ничего не добавляет; Esc → поля нет, фокус на «+» Schedule; при выделении клик только снимает его; текст переезжает в другой квадрант; «+» открывает поле; `goOffline` → добавление через поле, после `goOnline` задача в `serverTasks()`; axe с открытым полем. Тесты R1, ожидавшие форму по клику в пустом квадранте, обновлены.
- [x] Чек-лист: основной сценарий «Добавить задачу» переписан под поле; раздел G — клик по промежутку между карточками против начала drag, одна рамка фокуса в обеих темах.

## Comments

**Что сделано.**

- **Клик по пустому месту.** Квадрант различает пустое место и остальное: всё, кроме карточки (`option`), кнопок (заголовок, «+N below») и поля.
  - Без выделения клик открывает поле.
  - С выделенной задачей клик только снимает выделение.
  - Переходное решение R1 (форма по клику в пустом квадранте) убрано.
- **Поле.** Состояние в `uiStore.inlineAdd`: квадрант, текст и счётчик открытий.
  - Поле одно на странице, при открытии в другом квадранте текст переезжает вместе с ним.
  - Открытие снимает выделение.
  - Панель действий не показывается, пока поле открыто.
  - Enter добавляет обрезанный текст через `addTaskAction` в конец квадранта, молча и без выделения.
  - Esc закрывает поле и ставит фокус на «+» квадранта.
  - Уход фокуса закрывает поле, только если оно пустое.
  - Поле ограничено 200 символами (`maxLength`), Enter во время IME-композиции игнорируется.
  - Смена вида на List закрывает поле.
- **«+» в заголовке.** Кнопка `Add a task to <квадрант>` с `tabindex="-1"`: 24px на desktop, 44px на телефоне.
  - В сетке телефона «+» — соседняя кнопка рядом с «Open … full screen», а не вложенная в неё. Так фокусу после Esc всегда есть куда вернуться.
  - Раскрытие квадранта по «+» на телефоне — тикет 03.
- **Рамка поля.** Пунктирная рамка цвета квадранта при фокусе становится сплошной, outline выключен. На фоне 200 рамка 700, в тёмной теме 400; контраст ≥ 4:1 в обеих темах (посчитан по oklch Tailwind).
- **Полоски вставки убраны.** `InsertTaskZone`, `taskInsertIndex`, `setTaskInsertIndexAction` и параметр `index` у `addTaskAction` и `openFormWithCategoryAction` удалены. Промежутки между карточками теперь дают `gap-2` списка, клик по ним — пустое место. FAB «New task» работает как раньше.

**Где лежит.**

- `src/features/addTask`:
  - `ui/InlineAddField` — поле;
  - `ui/QuadrantAddButton` — «+»;
  - `lib/addButtonId`, `lib/scrollIntoArea`;
  - `consts` — длина, рамки, стили.
- Сущность `entities/matrixLayout` фичу не импортирует: она объявляет тип слотов `QuadrantSlots` (`headerAction`, `listEnd`, `onEmptySpaceClick`). Слоты заполняет виджет `widgets/taskMatrix` (`QUADRANT_SLOTS`), `InteractWithMatrix` передаёт их в `MatrixLayout`.
- Прокрутка квадранта перенесена с `ul[role=listbox]` на обёртку (`LIST_STYLES.SCROLL_AREA`). Причина: поле внутри `listbox` axe считает недопустимым потомком (`aria-required-children`). Поле стоит после списка в той же прокручиваемой области. `tasksBelow`/`scrollTopBelow` считают задачи внутри области.
- Тесты:
  - новые — `src/app/tests/inlineAdd.test.tsx` (15 сценариев из тикета, включая офлайн вошедшего и axe с открытым полем);
  - обновлены `selectionPanel.test` (два теста R1 про форму в пустом квадранте), `moreBelow.test` и хелперы `listLayout.ts` и `drag.ts` (новая обёртка прокрутки).
- Чек-лист `docs/agents/a11y-checklist.md`:
  - переписан основной сценарий «Добавить задачу»;
  - в разделе F поправлен шаг 2;
  - добавлен раздел G.
- Визуально проверено в Chromium (1280px, светлая и тёмная тема, 390px):
  - поле в конце списка;
  - сплошная рамка при фокусе и пунктирная с текстом без фокуса;
  - переполненный квадрант прокручивается к полю, «+N below» пропадает;
  - страница при этом не прыгает.

**Известные ограничения.**

- **Выделение при открытом поле с текстом.** Если с таким полем кликнуть по задаче или дойти до неё Tab, задача выделяется, но панели нет: так требует критерий «панель закрыта, пока поле открыто». Клавиши C/E/Del/1–4 при этом действуют на выделенную задачу без видимой панели, Tab из задачи в панель не ведёт. Для клавиатуры это неочевидно. Варианты на решение: снимать выделение, пока поле открыто, или показывать панель, когда фокус ушёл из поля.
- **Нет jest-теста на прокрутку к полю и пересчёт «+N below».** `mockListLayout` не раскладывает поле; поведение проверено в браузере и внесено в раздел G чек-листа.
- **Промах по карточке.** Нажатие на карточку, отпущенное без drag над промежутком (сдвиг < 5px), кликает по общему предку, то есть по пустому месту. Так было и в R1 со снятием выделения; пункт есть в разделе G чек-листа.
- **Лимит 200 символов записан в трёх местах**: `MAX_TASK_LENGTH` фичи, литерал `200` в `addTaskAction` и `EditTaskForm`. В `shared` не вынесен, чтобы не расширять тикет.
- **Фокус после Esc** сейчас всегда уходит на «+» квадранта. Возврат к задаче или «Add a task» при `N`/`1–4` — тикет 02.

# 03: Поле на телефоне

**What to build:** На телефоне печатать в ячейке шириной 170px под экранной клавиатурой невозможно, поэтому тап по пустому месту ячейки или по «+» раскрывает квадрант на весь экран с полем внизу. Срез G [спеки R3](../spec.md) (дополнение спеки), решения: [Обнаружимость действий над задачей](../../ui-ux-audit/issues/05-task-actions-discoverability.md), [Мобильная матрица](../../ui-ux-audit/issues/06-mobile-matrix.md).

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] Ниже 640px (сетка 2×2) тап по пустому месту ячейки или по её «+» раскрывает квадрант на весь экран (R1, тикет 16) с полем в конце списка и фокусом в нём. В раскрытом квадранте поле работает как на desktop.
- [ ] «Back to matrix» закрывает поле.
- [ ] «+» в ячейке — соседняя кнопка рядом с кнопкой-заголовком «Open … full screen», не вложена в неё; цель не меньше 44×44, заголовок остаётся не ниже 44px.
- [ ] Пока поле открыто на телефоне, FAB «New task» скрыт, как при открытой панели.
- [ ] Тесты на главном seam (375px, coarse): тап по пустому месту ячейки — раскрытый квадрант, в фокусе `textbox` «Add task to …», кнопки «New task» нет; Enter добавляет, поле остаётся; «Back to matrix» — сетка без поля; axe без `nested-interactive`.
- [ ] Чек-лист, раздел G: iPhone — поле не прячется под экранной клавиатурой, «+» легко попасть пальцем, VoiceOver на iOS читает «Add a task to …, кнопка».

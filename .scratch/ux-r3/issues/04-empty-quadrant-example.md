# 04: Пустой квадрант: пример и CTA

**What to build:** Пустой квадрант объясняет метод сам: показывает, что сюда класть, и что по нему можно кликнуть. Срез I [спеки R3](../spec.md), решение: [Онбординг первого визита](../../ui-ux-audit/issues/08-first-visit-onboarding.md), строка «Пример + CTA в пустом квадранте». Закрывает F3.

**Blocked by:** 02, 03, 17 (кнопка «Add a task»; G и Q уходят в `main` до I)

**Status:** ready-for-agent

- [ ] В пустом квадранте строка примеров из словаря квадрантов (`examples`, совпадает со страницей `/eisenhower-matrix`), под ней кнопка из тикета 02 с видимым текстом «Click to add a task» при мыши и «Tap to add» при touch (`(hover: none) and (pointer: coarse)`, не по ширине).
- [ ] Доступное имя кнопки совпадает с видимым текстом (WCAG 2.5.3), квадрант передаётся описанием по названию квадранта.
- [ ] Видно всегда, пока квадрант пуст, во всех ширинах, включая ячейку телефона и раскрытый квадрант.
- [ ] Холодный старт вошедшего без сети (J2): примеров нет, «Click to add a task» остаётся.
- [ ] Контраст примеров и CTA не меньше 4.5:1 на фонах квадрантов в обеих темах.
- [ ] Тесты на главном seam: пустой Delegate показывает свои примеры и «Click to add a task»; при `pointer: 'coarse'` — «Tap to add»; клик по кнопке открывает поле; холодный старт `deviceCache: 'empty'` + `offline` — примеров нет, кнопка есть; axe.
- [ ] Чек-лист, раздел I: контраст в обеих темах, ноутбук с сенсорным экраном и мышью показывает вариант для мыши, VoiceOver читает кнопку с названием квадранта.

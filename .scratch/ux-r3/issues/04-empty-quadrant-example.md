# 04: Пустой квадрант: пример и CTA

**What to build:** Пустой квадрант объясняет метод сам: показывает, что сюда класть, и что по нему можно кликнуть. Срез I [спеки R3](../spec.md), решение: [Онбординг первого визита](../../ui-ux-audit/issues/08-first-visit-onboarding.md), строка «Пример + CTA в пустом квадранте». Закрывает F3.

**Blocked by:** 02, 03, 17 (кнопка «Add a task»; G и Q уходят в `main` до I)

**Status:** resolved

- [x] В пустом квадранте строка примеров из словаря квадрантов (`examples`, совпадает со страницей `/eisenhower-matrix`), под ней кнопка из тикета 02 с видимым текстом «Click to add a task» при мыши и «Tap to add» при touch (`(hover: none) and (pointer: coarse)`, не по ширине).
- [x] Доступное имя кнопки совпадает с видимым текстом (WCAG 2.5.3), квадрант передаётся описанием по названию квадранта.
- [x] Видно всегда, пока квадрант пуст, во всех ширинах, включая ячейку телефона и раскрытый квадрант.
- [x] Холодный старт вошедшего без сети (J2): примеров нет, «Click to add a task» остаётся.
- [x] Контраст примеров и CTA не меньше 4.5:1 на фонах квадрантов в обеих темах.
- [x] Тесты на главном seam: пустой Delegate показывает свои примеры и «Click to add a task»; при `pointer: 'coarse'` — «Tap to add»; клик по кнопке открывает поле; холодный старт `deviceCache: 'empty'` + `offline` — примеров нет, кнопка есть; axe.
- [x] Чек-лист, раздел I: контраст в обеих темах, ноутбук с сенсорным экраном и мышью показывает вариант для мыши, VoiceOver читает кнопку с названием квадранта.

## Comments

**Что сделано.**

- **Примеры.** `QuadrantExamples` (новый подкомпонент `entities/matrixLayout`) показывает `QUADRANTS[quadrant].examples` — тот же словарь, что на `/eisenhower-matrix`. `MatrixLayout` ставит его над кнопкой, пока квадрант пуст. Курсив, `text-gray-700` / `dark:text-gray-300`.
- **CTA.** Кнопка «Add a task» из тикета 02 показывает «Click to add a task», а на touch «Tap to add». Тот же узел, та же остановка Tab и те же правила фокуса. Имя — видимый текст, описание — заголовок квадранта (`aria-describedby`), как и было. Пунктирное подчёркивание, сплошное при hover: так текст выглядит нажимаемым.
- **Touch** определяется новым `useIsTouchScreen` в `shared/hooks` (`(hover: none) and (pointer: coarse)`). `ActionToolbar` и `ToastCard` теперь зовут его вместо своей копии запроса.
- **Холодный старт.** `TaskMatrix` считает `isAccountAwaited` (вошёл, облачное хранилище, `isAwaitingServer`) и по нему показывает строку R2 и прячет примеры (`hasExamples` через `InteractWithMatrix` → `MatrixLayout`). `isAwaitingServer` ставится, только когда в кэше устройства нет облачной матрицы, поэтому примеры пропадают только при холодном старте. Кнопка остаётся.
- **Тексты.** Кнопка больше не называется «Add a task», поэтому шпаргалка (`←`/`→`) и раздел Keyboard на `/eisenhower-matrix` говорят «the button that adds a task». В чек-листе в разделе G поправлено то, что читает VoiceOver.

**Тесты.** Новый `src/app/tests/emptyQuadrant.test.tsx`:

- пустой Delegate — свои примеры и «Click to add a task» с описанием «Delegate»; примеры и кнопка есть только в пустых квадрантах;
- `pointer: 'coarse'` — «Tap to add», «Click to add a task» нет;
- телефон 375px: «Tap to add» и примеры в ячейке и в раскрытом Delegate;
- клик по кнопке — в фокусе `textbox` «Add task to Delegate»;
- холодный старт `deviceCache: 'empty'` + `offline` — строка R2 есть, примеров нет, кнопка есть;
- axe.

В `keyboardAdd.test` и `matrixKeyboard.test` имя кнопки заменено на «Click to add a task». Чек-лист: новый раздел I, блок «Пример и CTA в пустом квадранте».

**Проверено в Chrome.** Desktop 1280px в тёмной теме и эмуляция 375×667 с touch в светлой: ячейка и раскрытый Delegate, «Tap to add» открывает поле. Контраст по вычисленным цветам:
- примеры — 7.1–8.9 в светлой теме и 13.7 в тёмной;
- кнопка — 12.2–15.4 в светлой теме и 18.3 в тёмной.

Кнопка высотой 44px.

**Известные ограничения.**

- Пока поле открыто в ещё пустом квадранте, примеры и кнопка остаются над полем: «видно всегда, пока квадрант пуст».
- Ноутбук с сенсорным экраном и мышью и VoiceOver в эмуляции не проверяются. Пункты есть в чек-листе.

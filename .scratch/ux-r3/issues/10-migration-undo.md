# 10: Undo Migration

**What to build:** Пользователь, который не хотел переносить задачи, отменяет Migration кнопкой Undo в toast или `Ctrl/Cmd+Z`: аккаунт и устройство возвращаются как до входа, и приложение больше не предлагает перенос, пока он вошёл. Срез K [спеки R3](../spec.md) (дополнение спеки), решения: [Модель «одна матрица»](../../ui-ux-audit/issues/03-one-matrix-model.md), [Поведение toast-уведомлений](../../ui-ux-audit/issues/12-toast-behaviour.md).

**Blocked by:** 09

**Status:** ready-for-agent

- [ ] Toast Migration получает Undo; `Ctrl/Cmd+Z` отменяет Migration, пока toast виден.
- [ ] Undo удаляет перенесённые задачи из облака, возвращает их на устройство, если их уже очистили, и записывает на устройстве отказ для этого `uid`.
- [ ] С отказом правило Migration не срабатывает: перезагрузки перенос не повторяют. Отказ стирается при выходе, при следующем входе правило работает снова.
- [ ] Undo — ещё одна запись, без сети работает так же (R2). После Undo toast не показывается.
- [ ] Тесты на главном seam: Undo → облако как до входа (`serverTasks()`), `reload()` без переноса и toast; после Sign out задачи устройства на месте; повторный вход → перенос снова; `Ctrl+Z` при видимом toast делает то же; Undo без сети, затем `goOnline` — на сервере задач устройства нет.
- [ ] Чек-лист, раздел K: Undo после настоящего входа, в консоли Firebase задач устройства нет, после выхода они в матрице.

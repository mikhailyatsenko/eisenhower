# 14: Сегменты «Matrix | List»

**What to build:** Пользователь видит, какой вид открыт и какой ещё есть: сегменты «Matrix | List» с иконками в шапке вместо безымянной иконки-переключателя. Срез L [спеки R3](../spec.md), решение: [Шапка и навигация](../../ui-ux-audit/issues/07-header-navigation.md).

**Blocked by:** 13

**Status:** ready-for-agent

- [ ] В шапке сегменты с иконками и подписями «Matrix» и «List», у активного фон. На телефоне только иконки, доступные имена сохраняются.
- [ ] Разметка: `tablist` с именем «View», два `tab` с `aria-selected` и `aria-controls` на область вида; область вида — `tabpanel`, подписанный активной вкладкой, внутри прежняя группа «Task matrix».
- [ ] Клавиатура по паттерну WAI-ARIA tabs с автоматической активацией: в Tab-порядке только активная вкладка, ←→ переключают вид сразу; клик переключает вид. Снятие выделения при смене вида — как сейчас.
- [ ] Сегменты только на главной; на других страницах их нет.
- [ ] Прежний `ViewToggle` удалён.
- [ ] Тесты на главном seam: `tablist` «View», `tab` «Matrix» выбран; `→` выбирает «List» и показывает List view; одна вкладка в Tab-порядке; axe. Тест серверных страниц: на `/eisenhower-matrix` `tablist` нет.
- [ ] Чек-лист, раздел L: сегменты клавиатурой и VoiceOver («вкладка, выбрано, 1 из 2»), на телефоне иконки 44×44.

# 17: Снятие выделения: клик где угодно и кнопка «×»

**What to build:** Выделение снимается так, чтобы это нашёл любой пользователь. Сейчас клик снимает выделение только внутри рамки квадранта, а кнопки у панели нет. На телефоне пустого места мало: нижний ряд ячеек закрыт панелью, а Esc без клавиатуры недоступен. Нужны два способа: клик по любому неинтерактивному месту страницы и явная кнопка «×» в панели действий, на телефоне и на desktop. Срез Q [спеки R3](../spec.md) (дополнение спеки), решения: [Обнаружимость действий над задачей](../../ui-ux-audit/issues/05-task-actions-discoverability.md) (снятие выделения повторным кликом, кликом по пустому месту или Esc), [Минимальная планка доступности](../../ui-ux-audit/issues/11-accessibility-baseline.md).

**Blocked by:** 03 (G уходит в `main` до Q)

**Status:** resolved

- [x] Клик или тап по любому неинтерактивному месту страницы снимает выделение, а не только внутри рамки квадранта. Это поля страницы, зазоры между квадрантами, подписи осей, пустые места шапки и заголовка страницы, место под матрицей, футер. Внутри квадранта всё как раньше: при выделении тап по пустому месту только снимает выделение, поле не открывается (G).
- [x] Исключения: всё, что делает своё действие, выделение само не снимает.
  - Карточка задачи: выделяет её, а повторный клик снимает, как раньше.
  - Кнопки панели выполняют действие.
  - Toast с Undo выполняет Undo.
  - «+N below» прокручивает (H).
  - Модальные диалоги перехватывают клик сами.
  - Интерактивные элементы вне матрицы (тема, List view, Sign in, ссылки футера) и «Open … full screen» выделение не трогают.
  - «+» квадранта, как и раньше, снимает выделение, потому что открывает поле (G).
- [x] В панели действий кнопка «×» с доступным именем «Deselect task» и `aria-keyshortcuts="Escape"`.
  - На desktop — последняя в полосе, после Delete, через разделитель, с подсказкой `Esc` (на touch подсказки нет, как у других кнопок).
  - На телефоне — справа в строке с текстом задачи, цель не меньше 44×44.
  - Работает везде, где есть панель, в том числе в List view. (В List view панели пока нет, она приходит со срезом N в R4; «×» — часть панели и появится там вместе с ней.)
- [x] После «×» фокус на карточке этой задачи без выделения, как после Esc с задачи: панели нет, матрица остаётся одной остановкой Tab на этой задаче, стрелки продолжают с неё. Сейчас фокус на карточке сам выделяет задачу (`onFocus`), поэтому этот возврат фокуса выделять не должен. Кольцо фокуса видно только при работе с клавиатуры.
- [x] После клика по пустому месту фокус специально не переносится.
- [x] Шпаргалка `?` и страница `/eisenhower-matrix` («How to use the app») упоминают «×» рядом с Esc.
- [x] Тесты на главном seam:
  - клик по подписи оси и по месту под матрицей снимает выделение, панели нет;
  - клик по кнопке темы выделение не снимает;
  - «×» на desktop: панели нет, в фокусе невыделенная задача, `aria-selected="false"`;
  - «×» на телефоне (375px, coarse): панели нет, кнопка «New task» вернулась;
  - «×» в List view — отложено до среза N (R4): в List view нет выделения и панели;
  - axe с открытой панелью на desktop и на телефоне.
- [x] Чек-лист, раздел Q:
  - клик по полям, зазорам, осям и футеру на desktop;
  - тап по видимой части сетки над панелью и по «×» на iPhone, «×» легко попасть пальцем;
  - кольцо фокуса после «×» с клавиатуры и его отсутствие после клика мышью;
  - VoiceOver на macOS и iOS читает «Deselect task, кнопка».

## Comments

**Что сделано.**

- **Клик вне задачи.** `useDeselectOnPageClick` в `features/selectTask` слушает `click` на `document` и снимает выделение, если цель клика не делает своего действия. Исключения (`OWN_CLICK`): ссылки, кнопки и `[role="button"]`, поля, `label`, `summary`, карточка задачи, панель (`[role="toolbar"]`), `dialog` вместе с фоном и карточка toast (`TOAST_CARD_SELECTOR` из `shared/ui/toast`, атрибут `data-toast-card`). Внутри квадранта раньше срабатывает его собственный обработчик (G), поэтому поле при выделении не открывается. Фокус хук не трогает.
- **iOS.** Safari на iPhone доставляет тап по обычному элементу до слушателя на `document`, только если элемент выглядит кликабельным. Поэтому на touch у `main` и `footer` стоит `cursor: pointer` без подсветки тапа (`globals.css`). У квадранта `cursor-pointer` уже был.
- **«×» в панели** (`ActionToolbar`): `aria-label="Deselect task"`, `aria-keyshortcuts="Escape"`. Глиф «×» скрыт от screen reader.
  - Desktop: последняя, после Delete через разделитель, подсказка `Esc`, на touch подсказки нет.
  - Телефон: справа в строке с текстом задачи, 44×44.
- **Фокус после «×».** `handleDeselect` сначала фокусирует карточку, пока задача ещё выделена (её `onFocus` тогда ничего не делает), и только потом снимает выделение. Состояние то же, что после `Esc` с задачи: `↓` снова выделяет её, Tab-остановка по `lastSelectedTaskId`.
- **Кольцо фокуса у невыделенной карточки.** Раньше у сфокусированной, но не выделенной карточки кольца не было, в том числе после `Esc` (с R1). Теперь есть пунктирная `focus-visible`-обводка цвета индиго, отличная от сплошного кольца выделения. После клика мышью её нет. Находка ревью по спеке.
- **Тексты.** Строка `Esc` в шпаргалке и раздел «How to use the app» на `/eisenhower-matrix` (desktop и «On a phone») упоминают «×».

**Тесты.** Новый `src/app/tests/deselect.test.tsx`:

- клик по подписи оси, по `main` под матрицей и по футеру снимают выделение;
- клик по кнопке темы и по тексту toast его не снимают;
- «×» последняя в панели, `aria-keyshortcuts="Escape"`;
- после «×» мышью панели нет, задача в фокусе, `aria-selected="false"`; «×» с клавиатуры, затем `↓` выделяет её снова;
- телефон (375px, coarse): после «×» панели нет, «New task» вернулась;
- axe с панелью на desktop и телефоне.

`mobileActionPanel.test` и `matrixKeyboard.test` обновлены под новую кнопку. Чек-лист: раздел Q.

**Проверено в Chromium** (1280px и эмуляция 375×812 с touch):

- клик по полю страницы, зазорам между квадрантами, подписи оси, строке заголовка и шапке снимает выделение;
- кнопка темы выделение не снимает;
- «×» мышью: без кольца фокуса; «×» с клавиатуры: пунктирное кольцо, затем `↓` снова выделяет;
- на телефоне тап по зазору сетки над панелью, «×» 44×44 в сетке и в квадранте на весь экран;
- drag другой задачи при выделении выделение не снимает (dnd-kit подавляет клик после drag).

**Известные ограничения.**

- **List view.** «×» там появится вместе с панелью в срезе N (R4). Тест отложен туда же.
- **`Esc` на самой «×»** возвращает фокус на задачу и оставляет выделение, как `Esc` из любой кнопки панели (R1). Значит, `aria-keyshortcuts="Escape"` описывает `Esc` с задачи, а не нажатие на кнопке. Атрибут задан спекой, поведение `Esc` в панели не менялось.
- **iPhone и VoiceOver** в эмуляции не проверяются: тап по полям страницы (зависит от `cursor: pointer`), «×» пальцем, «Deselect task, кнопка». Эти пункты есть в чек-листе, раздел Q.

# 17: Снятие выделения: клик где угодно и кнопка «×»

**What to build:** Выделение снимается так, чтобы это нашёл любой пользователь. Сейчас клик снимает выделение только внутри рамки квадранта, а кнопки у панели нет. На телефоне пустого места мало: нижний ряд ячеек закрыт панелью, а Esc без клавиатуры недоступен. Нужны два способа: клик по любому неинтерактивному месту страницы и явная кнопка «×» в панели действий, на телефоне и на desktop. Срез Q [спеки R3](../spec.md) (дополнение спеки), решения: [Обнаружимость действий над задачей](../../ui-ux-audit/issues/05-task-actions-discoverability.md) (снятие выделения повторным кликом, кликом по пустому месту или Esc), [Минимальная планка доступности](../../ui-ux-audit/issues/11-accessibility-baseline.md).

**Blocked by:** 03 (G уходит в `main` до Q)

**Status:** ready-for-agent

- [ ] Клик или тап по любому неинтерактивному месту страницы снимает выделение, а не только внутри рамки квадранта. Это поля страницы, зазоры между квадрантами, подписи осей, пустые места шапки и заголовка страницы, место под матрицей, футер. Внутри квадранта всё как раньше: при выделении тап по пустому месту только снимает выделение, поле не открывается (G).
- [ ] Исключения: всё, что делает своё действие, выделение само не снимает.
  - Карточка задачи: выделяет её, а повторный клик снимает, как раньше.
  - Кнопки панели выполняют действие.
  - Toast с Undo выполняет Undo.
  - «+N below» прокручивает (H).
  - Модальные диалоги перехватывают клик сами.
  - Интерактивные элементы вне матрицы (тема, List view, Sign in, ссылки футера) и «Open … full screen» выделение не трогают.
  - «+» квадранта, как и раньше, снимает выделение, потому что открывает поле (G).
- [ ] В панели действий кнопка «×» с доступным именем «Deselect task» и `aria-keyshortcuts="Escape"`.
  - На desktop — последняя в полосе, после Delete, через разделитель, с подсказкой `Esc` (на touch подсказки нет, как у других кнопок).
  - На телефоне — справа в строке с текстом задачи, цель не меньше 44×44.
  - Работает везде, где есть панель, в том числе в List view.
- [ ] После «×» фокус на карточке этой задачи без выделения, как после Esc с задачи: панели нет, матрица остаётся одной остановкой Tab на этой задаче, стрелки продолжают с неё. Сейчас фокус на карточке сам выделяет задачу (`onFocus`), поэтому этот возврат фокуса выделять не должен. Кольцо фокуса видно только при работе с клавиатуры.
- [ ] После клика по пустому месту фокус специально не переносится.
- [ ] Шпаргалка `?` и страница `/eisenhower-matrix` («How to use the app») упоминают «×» рядом с Esc.
- [ ] Тесты на главном seam:
  - клик по подписи оси и по месту под матрицей снимает выделение, панели нет;
  - клик по кнопке темы выделение не снимает;
  - «×» на desktop: панели нет, в фокусе невыделенная задача, `aria-selected="false"`;
  - «×» на телефоне (375px, coarse): панели нет, кнопка «New task» вернулась;
  - «×» в List view;
  - axe с открытой панелью на desktop и на телефоне.
- [ ] Чек-лист, раздел Q:
  - клик по полям, зазорам, осям и футеру на desktop;
  - тап по видимой части сетки над панелью и по «×» на iPhone, «×» легко попасть пальцем;
  - кольцо фокуса после «×» с клавиатуры и его отсутствие после клика мышью;
  - VoiceOver на macOS и iOS читает «Deselect task, кнопка».

# 01: Дедлайн на карточке: дата и статус

**What to build:** Пользователь читает дедлайн словами: на карточке абсолютная дата в локали браузера и перед ней бейдж статуса вместо относительного «in 3 days». Срез M [спеки R4](../spec.md), раздел «M. Дедлайны и просрочка» (Модель, Статус, Когда статус обновляется, Формат даты, Карточка); решение: [Дедлайны и просрочка](../../ui-ux-audit/issues/15-deadlines-overdue.md), карточка из варианта B прототипа `prototype/deadlines`.

**Blocked by:** None (can start immediately)

**Status:** resolved

- [x] В модели `Task` необязательный признак «время задано»; дедлайн без времени — местная полночь с признаком `false`. Нет признака (все дедлайны до R4) — время задано. Облачный клиент пишет и читает поле в документе Firestore, отсутствующее читается как «время есть». Признак переживает правку, Complete, Undo, Move, Restore, удаление с Undo и Migration.
- [x] Чистая функция статуса: со временем Overdue после срока; без времени — после конца дня; Due today — сегодня и срок не прошёл; Due soon — завтра и послезавтра; дальше и без дедлайна статуса нет. Всё по местному календарю.
- [x] Чистая функция формата через `Intl` с локалью браузера: день недели, число, месяц коротко; год только не текущий; время только если задано; 12/24 часа по локали.
- [x] Карточка в матрице, на телефоне, в квадранте во весь экран и в List view: строка дедлайна «бейдж + дата». `⚠ OVERDUE` (декоративный `⚠` не читается), `DUE TODAY`, `DUE SOON`; у OVERDUE заливка бейджа и толстая левая полоса карточки. Статус и дата читаются вместе с задачей внутри `option`, без отдельного `aria-label`.
- [x] Статус пересчитывается раз в минуту и при возврате во вкладку; часы одни на страницу.
- [x] Относительное время и `title` с `dd/MM/yyyy HH:mm` ушли. Дата создания ушла с карточки List view (M1). Порядок задач дедлайн не меняет.
- [x] Контраст бейджей и даты ≥ 4.5:1 на всех квадрантах в обеих темах, полоса OVERDUE ≥ 3:1.
- [x] Seam 2 — таблица статуса и формата: граница минуты для дедлайна со временем; 00:00, 12:00, 23:59 и 00:00 следующего дня без времени; завтра/послезавтра/через три дня; вчера; задача без признака; en-GB, en-US, de-DE; год; переход через Новый год.
- [x] Главный seam: `setSystemTime` + сиды с дедлайном вчера / сегодня без времени / завтра / через неделю → «OVERDUE», «DUE TODAY», «DUE SOON», только дата; сегодня 9:00 при 8:59 → «DUE TODAY», после `advanceTimersByTime` на 2 минуты — «OVERDUE»; без времени время не показано; Complete+Undo и Move+Undo сохраняют признак; в List view нет даты создания; вошедший: признак в `serverTasks()` и после `reload()`; axe на карточке OVERDUE.
- [x] Чек-лист: раздел M «Дедлайн на карточке» — формат в en-GB, en-US, de-DE, ru-RU (язык браузера), контраст бейджей в обеих темах, смена бейджа в открытой вкладке, VoiceOver читает статус и дату с задачей.

## Comments

**Что сделано.**

- **Модель:** `Task.hasDueTime?: boolean`. `false` — дедлайн на весь день (местная полночь), нет поля — время задано, как у всех дедлайнов до R4. Облако пишет `hasDueTime` рядом с `dueDate` (`null` без дедлайна) и читает отсутствующее как `true` (`taskToDocData`, `toCloudSnapshot`, таблица в `cloudMatrixDocs.test`). Действия стора переносят задачу целиком, признак не теряется; план Migration тоже (`migrationPlan.test`). `editTaskAction` сбрасывает признак, только когда меняется дата: старая форма всегда даёт дату со временем. Тикет 02 передаст признак явно.
- **Статус** — `entities/matrixLayout/lib/deadlineStatus` («дедлайн, признак, сейчас → overdue | today | soon | null»), по местному календарю через `differenceInCalendarDays`.
- **Формат** — `shared/lib/formatDate` («дата, { hasTime, now, locale? } → строка»), один вызов `toLocaleString` с `weekday/day/month: short`, `year` только для другого года, `hour: numeric, minute: 2-digit` только со временем. В `shared` сразу: форма (02) и Completed (07) берут его же. В en-GB `Fri 25 Sept, 9:00`, в en-US `Fri, Sep 25, 9:00 AM`, в de-DE `Fr., 25. Sept., 9:00`.
- **Часы** — `shared/hooks/useNow`: одни на страницу (`useSyncExternalStore` с общим `setInterval` раз в минуту, пока есть подписчики) плюс пересчёт на `visibilitychange`. Карточки берут статус через `useDeadlineStatus`.
- **Карточка:** `components/deadlineBadge` заменён на `components/deadlineLine` — бейдж словом и дата. `⚠` в `aria-hidden`, отдельного `aria-label` нет, имя `option` — «Pay rent OVERDUE Thu 24 Sept». Полоса `border-l-4` у OVERDUE на карточке матрицы, превью drag и карточке List view. На телефоне строка слева и переносится, от `sm` по центру, как текст карточки. В List view нет даты создания.
- **Контраст** посчитан по oklch Tailwind v4 на всех квадрантах: дата ≥ 7.6:1, приглушённый бейдж ≥ 7.4:1, OVERDUE (белый на red-800) 8.4:1, полоса ≥ 4.3:1 (светлая red-800 на red-300 — самый низкий случай), в тёмной red-400 ≥ 5.1:1.
- **Тесты:** seam 2 — `deadlineStatus.test` и `formatDate.test` (формат проверяется по частям, без пунктуации). Главный seam — `deadlineCard.test`: статусы и даты в `option`, время только у дедлайнов со временем и без признака, смена DUE TODAY → OVERDUE через `advanceTimersByTime`, пересчёт на `visibilitychange`, Complete/Move/Delete с Undo и `reload()`, правка текста, List view без даты создания, axe на OVERDUE, вошедший — признак на сервере и после `reload()`. У фейка облака новый `cloud.serverTask(text)`: `serverTasks()` отдаёт только тексты. `selectionPanel.test` проверяет дату с годом вместо «in N years».
- **Чек-лист:** раздел M «Дедлайн на карточке»; пункт VoiceOver раздела F теперь «Pay rent, OVERDUE, Thu 24 Sept».

**Ревью (стандарты и спека), что оставлено.** `useNow` и `formatDate` в `shared` при одном потребителе — сознательно, их ждут тикеты 02 и 07. Правило «нет признака — время есть» записано в статусе, строке и облачном маппинге отдельно. Тройка «статус + полоса + проп» повторяется в `TaskItem`, `TaskDragPreview` и `ListTaskItem`. `ListTaskItem` уходит в срезе N, тогда останутся два места. `today` и `soon` делят одну приглушённую заливку: их различает слово.

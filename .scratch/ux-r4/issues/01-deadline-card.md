# 01: Дедлайн на карточке: дата и статус

**What to build:** Пользователь читает дедлайн словами: на карточке абсолютная дата в локали браузера и перед ней бейдж статуса вместо относительного «in 3 days». Срез M [спеки R4](../spec.md), раздел «M. Дедлайны и просрочка» (Модель, Статус, Когда статус обновляется, Формат даты, Карточка); решение: [Дедлайны и просрочка](../../ui-ux-audit/issues/15-deadlines-overdue.md), карточка из варианта B прототипа `prototype/deadlines`.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] В модели `Task` необязательный признак «время задано»; дедлайн без времени — местная полночь с признаком `false`. Нет признака (все дедлайны до R4) — время задано. Облачный клиент пишет и читает поле в документе Firestore, отсутствующее читается как «время есть». Признак переживает правку, Complete, Undo, Move, Restore, удаление с Undo и Migration.
- [ ] Чистая функция статуса: со временем Overdue после срока; без времени — после конца дня; Due today — сегодня и срок не прошёл; Due soon — завтра и послезавтра; дальше и без дедлайна статуса нет. Всё по местному календарю.
- [ ] Чистая функция формата через `Intl` с локалью браузера: день недели, число, месяц коротко; год только не текущий; время только если задано; 12/24 часа по локали.
- [ ] Карточка в матрице, на телефоне, в квадранте во весь экран и в List view: строка дедлайна «бейдж + дата». `⚠ OVERDUE` (декоративный `⚠` не читается), `DUE TODAY`, `DUE SOON`; у OVERDUE заливка бейджа и толстая левая полоса карточки. Статус и дата читаются вместе с задачей внутри `option`, без отдельного `aria-label`.
- [ ] Статус пересчитывается раз в минуту и при возврате во вкладку; часы одни на страницу.
- [ ] Относительное время и `title` с `dd/MM/yyyy HH:mm` ушли. Дата создания ушла с карточки List view (M1). Порядок задач дедлайн не меняет.
- [ ] Контраст бейджей и даты ≥ 4.5:1 на всех квадрантах в обеих темах, полоса OVERDUE ≥ 3:1.
- [ ] Seam 2 — таблица статуса и формата: граница минуты для дедлайна со временем; 00:00, 12:00, 23:59 и 00:00 следующего дня без времени; завтра/послезавтра/через три дня; вчера; задача без признака; en-GB, en-US, de-DE; год; переход через Новый год.
- [ ] Главный seam: `setSystemTime` + сиды с дедлайном вчера / сегодня без времени / завтра / через неделю → «OVERDUE», «DUE TODAY», «DUE SOON», только дата; сегодня 9:00 при 8:59 → «DUE TODAY», после `advanceTimersByTime` на 2 минуты — «OVERDUE»; без времени время не показано; Complete+Undo и Move+Undo сохраняют признак; в List view нет даты создания; вошедший: признак в `serverTasks()` и после `reload()`; axe на карточке OVERDUE.
- [ ] Чек-лист: раздел M «Дедлайн на карточке» — формат в en-GB, en-US, de-DE, ru-RU (язык браузера), контраст бейджей в обеих темах, смена бейджа в открытой вкладке, VoiceOver читает статус и дату с задачей.

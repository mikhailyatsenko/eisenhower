# 02: Форма дедлайна: чипы и нативные поля

**What to build:** Пользователь задаёт срок одним нажатием или системным пикером, время необязательно, и до сохранения видит, как дедлайн будет выглядеть на карточке. Срез M [спеки R4](../spec.md), раздел «M. Дедлайны и просрочка» (Форма); решение: [Дедлайны и просрочка](../../ui-ux-audit/issues/15-deadlines-overdue.md), форма из варианта A прототипа `prototype/deadlines`.

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] Одна форма для «New task» и правки: группа «Deadline» с видимой подписью, чипы No deadline / Today / Tomorrow / This weekend / Next week. Чип ставит дату без времени и убирает время; No deadline снимает дедлайн.
- [ ] Даты чипов: Today — сегодня, Tomorrow — завтра, This weekend — ближайшая суббота (в субботу и воскресенье — сегодня), Next week — понедельник следующей недели.
- [ ] Выбранный чип — `aria-pressed="true"`: его дата совпадает с полем и время не задано; No deadline — когда дедлайна нет. На телефоне чипы не меньше 44×44.
- [ ] Нативный `<input type="date">` с видимым `<label>` «Date»; ручной ввод даты — дедлайн без времени. Дата в прошлом допустима. Невалидная дата — прежняя ошибка.
- [ ] «+ Add time» открывает нативный `<input type="time">` с `<label>` «Time» (по умолчанию 9:00, фокус в нём) и «Remove time» (фокус на «+ Add time»). Пустая дата снимает время.
- [ ] Под полями «Shows on card as: …» тем же форматом и бейджем, что карточка (01); без дедлайна превью нет; не live-регион.
- [ ] Форма пишет признак «время задано» через действия стора; вошедший без сети — в Pending changes (R2).
- [ ] `react-datepicker`, его типы, `datepicker.css`, пресеты +3h / +24h / +3d / +1w и переключатель «есть дедлайн» удалены; `date-fns` — только если ещё используется.
- [ ] Главный seam: у поля даты подпись «Date»; «Tomorrow» → `aria-pressed`, превью с «DUE SOON», сохранить → «DUE SOON» на карточке; «+ Add time» → фокус в «Time», время в превью; «Remove time» → фокус на «+ Add time»; «No deadline» снимает дедлайн; правка задачи до R4 (без признака) показывает и сохраняет время; вошедший `goOffline` → правка видна сразу, после `goOnline` на сервере; в DOM нет `react-datepicker`; axe на форме с открытым временем. Даты чипов — в таблице seam 2, если вынесены в чистую функцию, иначе на главном seam (пятница, суббота, воскресенье, понедельник).
- [ ] Чек-лист: шаг 3 основного сценария «Добавить задачу» (чипы и поля вместо datepicker); раздел M «Форма дедлайна» — системные пикеры на iPhone и Android, клавиатура по чипам и полям, VoiceOver «Tomorrow, кнопка, выбрано», подписи «Date» и «Time».
- [ ] Закрыт последний тикет среза M: предложить PR `ux-r4` → `main` с проверкой на Vercel preview.

# 03: Секции List view без сортировок

**What to build:** Пользователь видит в List view ту же матрицу сверху вниз: четыре секции в порядке приоритета с липкими подписанными заголовками, которые сворачиваются, а select'ов сортировки больше нет. Срез N [спеки R4](../spec.md), раздел «N. List view по секциям» (Раскладка, Порядок); решение: [Роль List view](../../ui-ux-audit/issues/10-list-view-role.md), вариант C прототипа `prototype/mobile-matrix` (`walkthrough/proto-06-C.png`).

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] Одна колонка по центру (`max-w-2xl`), секции Do First, Schedule, Delegate, Eliminate; задачи в порядке квадранта; текст по левому краю без ограничения строк; карточка — та же, что в матрице, со строкой дедлайна M.
- [ ] Липкий заголовок под шапкой и полосой синхронизации (`--top-bars-height`): декоративный значок 2×2 с подсвеченной ячейкой, название, критерии, счётчик. Заголовок — `h2` с кнопкой: `aria-expanded`, `aria-controls` на список, имя «Do First, 3 tasks» («1 task»). Кнопки заголовков — обычные остановки Tab.
- [ ] Список секции — `listbox` с именем квадранта. Свёрнутая секция рендерит только заголовок.
- [ ] Пустая секция всегда раскрыта, показывает пример и «Click to add a task» / «Tap to add» из I; кнопки сворачивания у неё нет. Сохранённое «свёрнуто» возвращается с первой задачей.
- [ ] Сворачивание по квадранту запоминается в сохраняемом `uiStore`, не синхронизируется, по умолчанию всё раскрыто. С `prefers-reduced-motion` — мгновенно.
- [ ] Select'ы «Sort by» / «Order», `sortField`, `sortDirection` и их действия удалены; старые сохранённые ключи игнорируются.
- [ ] Действия над задачей пока прежние, с кнопок карточки (выделение придёт в 04). Блок Completed пока под списком.
- [ ] Главный seam: четыре `listbox` по порядку, задачи в порядке квадранта, select'ов нет; кнопка «Do First, 2 tasks» `aria-expanded="true"` → клик → `false`, `listbox` нет → `reload()` свёрнута; пустая секция с примером и без кнопки сворачивания; вошедший без сети — облачная матрица, пустые секции без примеров; axe в List view с раскрытыми, свёрнутыми и пустыми секциями. Тесты, ждавшие ленту, переходят на секции.
- [ ] Чек-лист: раздел N «Секции» — липкие заголовки на 320/390/1280px и с полосой офлайна, свёрнутые после перезагрузки, контраст подписей и счётчиков, VoiceOver «Do First, 2 tasks, развёрнуто, кнопка» и секция как список.

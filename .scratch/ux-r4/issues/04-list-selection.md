# 04: Выделение, панель и клавиши в List view

**What to build:** Пользователь действует в List view так же, как в матрице: выделяет задачу кликом или клавиатурой, работает через ту же панель и клавиши, ходит стрелками по секциям; drag нет. Срез N [спеки R4](../spec.md), раздел «N. List view по секциям» (Выделение и действия, Клавиатура в списке, Drag в списке нет); решения: [Роль List view](../../ui-ux-audit/issues/10-list-view-role.md), [Обнаружимость действий](../../ui-ux-audit/issues/05-task-actions-discoverability.md), [Минимальная планка доступности](../../ui-ux-audit/issues/11-accessibility-baseline.md).

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] Задачи секций — `option` с `aria-selected`; клик или тап выделяет, повторный клик, клик по пустому месту страницы, Esc и «×» снимают (Q R3). Снизу та же панель Complete / Edit / Move to / Delete / «×», на телефоне телефонный вариант.
- [ ] Те же клавиши, что в матрице (Enter/E, C/Space, Delete/Backspace, `1–4` с выделением — Move, `?`, `Ctrl/Cmd+Z`). Фокус после Complete, Delete, Move: следующая задача секции, иначе предыдущая; после Undo — восстановленная.
- [ ] Весь список — одна остановка Tab с roving tabindex: последняя выделенная задача, если видна, иначе первая задача первой раскрытой секции.
- [ ] ↑↓ по задачам сквозь секции Do First → Eliminate, свёрнутые пропускаются, без кольца. ←→ — первая задача предыдущей/следующей раскрытой секции. На кнопке заголовка стрелки не перехватываются, Enter и Space сворачивают, фокус там задачу не выделяет.
- [ ] Свернуть секцию с Selected Task — выделение снято, фокус на кнопке заголовка. Move в свёрнутую секцию — секция остаётся свёрнутой, toast «Moved to …» с Undo.
- [ ] Строка подсказки из I показывается и под List view.
- [ ] Список без сенсоров drag, на телефоне прокрутка не начинает перенос. `ListTaskItem` с кнопками удалён.
- [ ] Главный seam: клик → `aria-selected`, `toolbar` «Actions for “…”»; Complete → следующая задача секции; `↓` с последней Do First → первая Schedule; `→` → следующая секция; свёрнутая пропускается; `2` с выделением → в «Schedule», `status` «Moved to Schedule»; свернуть с выделением → выделения нет, фокус на кнопке; Tab → последняя выделенная; «×» и клик по пустому месту (тест `deselect` переходит на секции); строка «Click a task to select it…» в List view; нет признаков dnd-kit draggable; телефон 390 + `coarse` — телефонная панель и «Tap a task to select it»; axe с панелью.
- [ ] Чек-лист: раздел N «Выделение в List view» — клавиатура по секциям, панель мышью и тапом, прокрутка на iPhone не начинает drag, VoiceOver на выделении.

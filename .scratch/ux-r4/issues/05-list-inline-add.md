# 05: Добавление в секциях List view

**What to build:** Пользователь добавляет задачу прямо в нужную секцию List view теми же способами, что в квадранте: «+», клик по пустому месту, `N` и `1–4`. Срез N [спеки R4](../spec.md), раздел «N. List view по секциям» (Добавление, Клавиатура в списке); решения: [Роль List view](../../ui-ux-audit/issues/10-list-view-role.md), G из [спеки R3](../../ux-r3/spec.md).

**Blocked by:** 04

**Status:** resolved

- [x] «+» в заголовке секции (вне Tab-порядка, имя «Add a task to <квадрант>», 44×44 на телефоне), клик по пустому месту секции (после последней задачи и в промежутках), `N` и `1–4` без выделения открывают инлайн-поле «Add task to <квадрант>» в конце секции. Правила G: при выделении клик по пустому месту только снимает выделение; Enter добавляет и оставляет поле; Esc закрывает с возвратом фокуса; поле одно, текст переезжает между секциями.
- [x] Поле в свёрнутой секции раскрывает её, раскрытие запоминается.
- [x] «Add a task» пустой секции — остановка ↑↓ и ←→ и Tab-остановка списка, если задач нет; фокус после опустения секции — на её «Add a task».
- [x] Подсказка «click empty space to add» и её флаг работают так же, как в матрице.
- [x] Главный seam: клик по пустому месту Schedule → `textbox` «Add task to Schedule», Enter → задача последней в секции, поле в фокусе; `2` без выделения → поле в Schedule; `N` при свёрнутой Do First → секция раскрыта (и после `reload()`), поле в фокусе; Complete последней задачи секции → фокус на её «Add a task»; `↓` заходит в пустую секцию на «Add a task»; вошедший без сети добавляет, после `goOnline` в `serverTasks()`; axe с открытым полем.
- [x] Чек-лист: раздел N «Добавление в секциях» — клик по промежутку, поле под экранной клавиатурой iPhone, одна рамка фокуса.

## Comments

**Что сделано.**

- **Слоты** — `TaskListView` подставляет в секции то же, что матрица в квадранты: «+» (`QuadrantAddButton`), `InlineAddField` в конце секции, `openInlineAddAction` для «Add a task» и `openInlineAddByEmptySpaceAction` для пустого места. Поле в секции получает `scrollsPage`: секция сама не прокручивается, поэтому к полю прокручивается страница (`scrollIntoView` с `scroll-margin` под шапку и липкий заголовок секции), а не область, как в квадранте.
- **Пустое место** — правило квадранта «с выделением клик только снимает его, без выделения — поле» вынесено в `entities/matrixLayout/hooks/useEmptySpaceClick`, им пользуются `Quadrant` и тело секции в `ListLayout`. Пустое место секции — промежутки между задачами и `pb-6` под последней; промежуток между секциями и заголовок остаются «страницей» (только снимают выделение).
- **Клавиши** — `useMatrixKeys` в обоих видах открывает инлайн-поле (`N`, `1–4` без выделения, `N` с выделением — в её секции, `Esc` обратно на задачу). Ветка `openAdd` и `openFormWithCategoryAction` удалены.
- **Свёрнутая секция** — `openInlineAdd` в List view убирает секцию из `collapsedSections`, так что раскрытие сохраняется, как кликом по заголовку.
- **Подсказка** — `EmptySpaceHint` в заголовке каждой раскрытой секции; сама прячется на touch и уже 640px (`useIsPhone`; в матрице она и так только в широком заголовке, поведение там не меняется). Флаг `hasAddedByEmptySpace` общий.
- **Тесты** — `listAdd.test` на главном seam: пустое место, Enter оставляет поле, первый клик при выделении, «+» вне Tab и `Esc`, `Esc` после пустого места → «+», текст переезжает, «Click to add a task» пустой секции, `2` и `N` (с выделением и при свёрнутой Do First, с `reload()`), «+» свёрнутой секции, закрытие поля при сворачивании, фокус на «Add a task» после Complete последней задачи, `↓`/`←` через «Add a task», Tab-остановка пустого списка, вошедший без сети, axe с полем, подсказка. Тесты «форма по `1–4` в List view» (`matrixKeyboard`) и «форма из Click to add a task» (`listSections`) удалены: поведение заменено.
- **Чек-лист** — раздел N «Добавление в секциях».

**Решения, которых нет в тикете.**

- **Свернуть секцию с открытым полем закрывает его вместе с текстом** (в `setSectionCollapsedAction`). Иначе поле с текстом осталось бы открытым, но невидимым. Так же ведёт себя «Back to matrix» на телефоне.
- **Клавиши на кнопке заголовка при выделении** (открытый вопрос 04) оставлены как есть: `C`, `Delete`, `E` и `1–4` действуют на выделенную задачу, как при фокусе на «+» квадранта в матрице. Попасть на кнопку при выделении можно только `Shift+Tab`, панель у задачи видна. `N` на кнопке заголовка открывает поле по правилу G (секция последней выделенной, иначе Do First), а не в секции этого заголовка.
- Отступ между секциями перенесён внутрь секции (`pb-6` у тела, `gap-1` снаружи), чтобы место под последней задачей было кликабельным пустым местом.

**Ревью (стандарты и спека), что оставлено.** `useEmptySpaceClick` принимает колбэк при вызове, а не при создании: в `ListLayout` один хук на четыре секции. `viewMode === 'list'` в `openInlineAdd` — единственное ветвление стора по виду; если их станет больше, завести им одно место.

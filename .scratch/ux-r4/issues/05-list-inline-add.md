# 05: Добавление в секциях List view

**What to build:** Пользователь добавляет задачу прямо в нужную секцию List view теми же способами, что в квадранте: «+», клик по пустому месту, `N` и `1–4`. Срез N [спеки R4](../spec.md), раздел «N. List view по секциям» (Добавление, Клавиатура в списке); решения: [Роль List view](../../ui-ux-audit/issues/10-list-view-role.md), G из [спеки R3](../../ux-r3/spec.md).

**Blocked by:** 04

**Status:** ready-for-agent

- [ ] «+» в заголовке секции (вне Tab-порядка, имя «Add a task to <квадрант>», 44×44 на телефоне), клик по пустому месту секции (после последней задачи и в промежутках), `N` и `1–4` без выделения открывают инлайн-поле «Add task to <квадрант>» в конце секции. Правила G: при выделении клик по пустому месту только снимает выделение; Enter добавляет и оставляет поле; Esc закрывает с возвратом фокуса; поле одно, текст переезжает между секциями.
- [ ] Поле в свёрнутой секции раскрывает её, раскрытие запоминается.
- [ ] «Add a task» пустой секции — остановка ↑↓ и ←→ и Tab-остановка списка, если задач нет; фокус после опустения секции — на её «Add a task».
- [ ] Подсказка «click empty space to add» и её флаг работают так же, как в матрице.
- [ ] Главный seam: клик по пустому месту Schedule → `textbox` «Add task to Schedule», Enter → задача последней в секции, поле в фокусе; `2` без выделения → поле в Schedule; `N` при свёрнутой Do First → секция раскрыта (и после `reload()`), поле в фокусе; Complete последней задачи секции → фокус на её «Add a task»; `↓` заходит в пустую секцию на «Add a task»; вошедший без сети добавляет, после `goOnline` в `serverTasks()`; axe с открытым полем.
- [ ] Чек-лист: раздел N «Добавление в секциях» — клик по промежутку, поле под экранной клавиатурой iPhone, одна рамка фокуса.

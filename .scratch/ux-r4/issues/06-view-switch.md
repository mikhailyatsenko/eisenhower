# 06: Смена вида: прокрутка наверх и без вспышки

**What to build:** Пользователь при переключении Matrix ↔ List всегда видит новый вид сверху, а сохранённый List открывается сразу, без мелькания матрицы. Срез N [спеки R4](../spec.md), раздел «N. List view по секциям» (Переключение вида); решение: [Роль List view](../../ui-ux-audit/issues/10-list-view-role.md); долг из Comments [тикета 14 R3](../../ux-r3/issues/14-view-segments.md).

**Blocked by:** 03 (по коду; в срезе идёт последним, PR среза N — после 05 и 06)

**Status:** ready-for-agent

- [ ] Смена вида вкладками (клик, ←→) прокручивает страницу наверх сразу, без плавной прокрутки (L4). Прокрутка — внутри одного пути смены вида, чтобы O мог добавить к нему явное исключение.
- [ ] Смена вида по-прежнему снимает выделение и закрывает поле. По умолчанию, и на телефоне, Matrix.
- [ ] Пока `uiStore` не прочитан из localStorage, область вида показывает лоадер, ни одна вкладка не выбрана, место под вкладками зарезервировано (шапка не прыгает). После чтения сразу сохранённый вид, `tablist` с одной `aria-selected` вкладкой в тот же кадр. Ошибок гидратации нет.
- [ ] Главный seam: смена вида вызывает `scrollTo` наверх; `reload()` с сохранённым List: до чтения стора нет выбранной `tab` и нет матрицы, после — выбран «List» и показан List view, Matrix ни разу не рендерилась; axe во время лоадера (`aria-controls` указывает на панель).
- [ ] Чек-лист: раздел N «Смена вида» — прокрутка наверх из середины длинной матрицы и списка, нет вспышки Matrix при сохранённом List на медленной сети (DevTools → Slow 3G).

# 02: Правка текста на месте

**What to build:** Пользователь исправляет текст задачи прямо в панели действий, без модального окна. Edit, `E` или `Enter` превращают панель в поле с текстом задачи, карточка показывает черновик вживую. `Enter` сохраняет, `Esc` отменяет. Диалог Edit уходит из приложения. Это срез S [спеки R5](../spec.md), разделы «S. Правка текста на месте» и «Шпаргалка `?` и страница метода». Решения: [Правка текста на месте](../../editing/issues/02-inline-text-edit.md), вариант B прототипа `prototype/inline-text-edit` (`9c7422d`, `?variant=B`); [Судьба диалога Edit и плавающей кнопки](../../editing/issues/05-edit-dialog-and-float-button.md). Прототип только для справки.

**Blocked by:** 01 — Срок кнопкой Deadline. Работа в ветке `ux-r5`. После тикета предложить PR `ux-r5` → `main` (срез S) с проверкой на Vercel preview.

**Status:** ready-for-agent

- [ ] Кнопка Edit, `E` или `Enter` на выделенной задаче превращают панель в поле правки, поверх ничего не открывается. Весь текст в поле сразу выделен. Повторный клик по задаче, как и раньше, снимает выделение. Названия Edit, `E` и `Enter` прежние.
- [ ] Десктоп: одна строка — «← Back» с подсказкой `Esc`, поле шириной `min(40rem, 100vw − 16rem)` и «Save» с подсказкой `Enter`. Поле растёт по высоте до `max-h-40`, дальше прокручивается. Back и Save выровнены по верху поля.
- [ ] Телефон: верхняя строка «← Back», «Edit text», «Save», под ней поле на всю ширину. Панель поднимается над экранной клавиатурой по `visualViewport`. Это один хук в `shared/hooks`, его переиспользует лента T.
- [ ] Доступность: панель — группа «Edit text of “<исходный текст>”». Поле — `textarea` с именем «Task text». Ошибка и счётчик связаны с полем через `aria-describedby`. При ошибке у поля `aria-invalid="true"`, ошибка в `role="alert"`, счётчик сам не объявляется.
- [ ] Карточка во время правки обведена пунктиром и показывает черновик, пустой черновик — «(empty)» приглушённо. Черновик лежит в `uiStore`: его пишет панель, читает карточка. Выделение остаётся, фокус держит поле, карточка не перехватывает клавиши.
- [ ] Текст одной строкой по смыслу: переносы при вставке становятся пробелами, `Enter` и `Shift+Enter` перенос не ставят. Лимит 200 символов (`maxLength`), счётчик `NNN/200` появляется с 170 и краснеет на 200. Контраст счётчика ≥ 4.5:1 в обоих состояниях.
- [ ] `Enter` и Save сохраняют текст после trim. Если текст пуст после trim, показывается «A task needs some text», поле остаётся открытым, ошибка уходит при вводе. Неизменённый текст не пишется. Срок и квадрант не меняются. Запись через `editTaskAction` только с текстом, без Toast и Undo, без сети — Pending changes.
- [ ] `Esc` и «← Back» отменяют. После сохранения или отмены панель снова обычная, фокус на задаче, выделение остаётся. Выбор другой задачи, снятие выделения, смена вида, начало drag и удаление задачи на другом устройстве закрывают правку без сохранения.
- [ ] Клавиши страницы (C, 1–4, Del, `?`, `Ctrl/Cmd+Z`…) в поле не работают, `Ctrl/Cmd+Z` отменяет ввод браузером. Во время правки кнопки Deadline нет, `D` печатает букву.
- [ ] Чистка по тикету 05 (сверить поиском по `src`). Удаляется `EditTaskDialog` и его экспорт. В `TaskActionPanel` уходят `editingTaskId`, `handleSave` для диалога и рендер диалога. `EditTaskForm` и `DeadlineFields` остаются до T: ими пользуется «New task». Ветки формы, нужные только правке, можно упростить, если это не мешает T.
- [ ] Тесты, которые правили через диалог «Edit task» (`dialogs`, `selectionPanel`, `quadrantVocabulary`, `noErrorToast`, `validationAfterBlur`, `offlineWrites`, `deadlineForm` и другие по поиску), переходят на правку на месте и кнопку Deadline. Проверки без замены (фон, клик по фону, фокус в диалоге, смена квадранта в форме) удаляются.
- [ ] Шпаргалка и страница метода. Строка `E`/`Enter`: «Edit the task’s text right in the action panel: Enter saves, Esc cancels». В пункте о панели на странице метода — «text field».
- [ ] Главный seam. Edit, `E` и `Enter` открывают поле «Task text» со всем выделенным текстом (`selectionStart` 0, `selectionEnd` равен длине) и группу «Edit text of “…”». Черновик и «(empty)» видны в `option`. `Enter` и Save сохраняют, фокус на задаче, `aria-selected`. `Esc` и «← Back» возвращают исходный текст. Пустой текст даёт `alert` и `aria-invalid`. Вставка с переносом сохраняется с пробелом. 170 символов — «170/200», на 200 ввод не идёт. Неизменённый текст не даёт записи в `serverTasks()`. Клик по другой задаче закрывает правку. `C`/`2`/`Delete`/`?` в поле задачи не трогают. `dialog` «Edit task» в DOM нет. List view. Телефон («Edit text», Save сверху). Вошедший без сети. `serverPages.test`. axe: панель правки на десктопе и телефоне, с ошибкой и со счётчиком.

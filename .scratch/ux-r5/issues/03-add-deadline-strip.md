# 03: Лента срока при добавлении

**What to build:** Пользователь задаёт срок прямо при добавлении в квадрант или секцию. Пока открыто inline-поле, внизу на месте панели действий стоит лента срока для набираемой задачи: чипы, дата, «+ Time» и кнопка «Add without deadline» / «Add · Thu 15 Oct». С клавиатуры: `2`, текст, `Tab`, `M`, `Enter`. Это первая половина среза T [спеки R5](../spec.md), раздел «T. Добавление со сроком без New task» → «Лента срока». Решение: [Добавление задачи сразу со сроком](../../editing/issues/04-add-with-deadline.md), вариант D прототипа `prototype/add-with-deadline` (`?variant=D`). Прототип только для справки.

**Blocked by:** 02 — Правка текста на месте. Работа в ветке `ux-r5`. PR среза T после этого тикета не открывается: на десктопе лента пока заходит под «New task», и это состояние живёт только в ветке до тикета 04.

**Status:** ready-for-agent

- [ ] Лента видна, пока открыто inline-поле квадранта или секции List view. Панели действий при этом нет, как и сейчас, поэтому вместе они не видны. Состав: подпись «Deadline» (на десктопе), чипы Today / Tomorrow / This weekend / Next week / No deadline, поле даты, «+ Time», Add. Set нет. Чипы, их даты и буквы берутся из выбора срока R.
- [ ] Лента — группа «Deadline for the new task in <квадрант>». Чипы с `aria-pressed`, у поля даты подпись «Date» для screen reader'а.
- [ ] Add добавляет задачу так же, как `Enter` в поле. Надпись и доступное имя: «Add without deadline» или «Add · Thu 15 Oct» (формат M, при заданном времени — со временем). Пока текст пуст, Add неактивен. После добавления фокус возвращается в поле.
- [ ] Чип, дата и время применяются сразу. При вводе даты фокус остаётся в поле даты. `Enter` в поле даты или времени добавляет задачу, если текст не пуст. «+ Time» всегда рядом с датой, без даты ставит сегодня 9:00.
- [ ] Срок набираемой задачи хранится рядом с текстом поля в `uiStore` (`inlineAdd`). Он сбрасывается после каждого добавления и при закрытии поля (`Esc`, уход фокуса из пустого поля, смена вида). Когда поле переезжает в другой квадрант (клик по пустому месту, «+», `1–4`), текст и срок едут вместе, подпись ленты меняет квадрант.
- [ ] Клавиатура. `Tab` из поля переводит фокус на нажатый чип, без срока — на No deadline. В ленте работают `T`/`M`/`W`/`X`/`Del` через `keyLetter`, после чипа фокус возвращается в поле. `Esc` и `Shift+Tab` с первого элемента ленты тоже возвращают в поле, поле остаётся открытым. Клавиши матрицы в ленте не работают.
- [ ] Уход фокуса: пустое поле закрывается, только когда фокус ушёл и из поля, и из ленты. Переход в ленту поле не закрывает, поле с текстом остаётся открытым.
- [ ] Телефон. Лента прижата к низу и поднимается над клавиатурой хуком `visualViewport` из S. Верхняя строка — «Deadline · new task in <квадрант>» и Add. Под ней чипы с переносом строк, без дат под названием, и поле даты. Горизонтальной прокрутки нет, цели не ниже 44×44, квадрант открыт во весь экран, как сейчас.
- [ ] Запись: `addTaskAction(квадрант, текст, срок)`, задача встаёт в конец квадранта, без toast и без выделения. Без сети — Pending changes. `useToastClearance` учитывает ленту так же, как панель. Разбора срока из текста нет.
- [ ] Строки `Enter` и `Esc` таблицы `DEADLINE_SHORTCUTS` получают хвосты: «; while adding a task, add it» и «, or from the deadline strip back to the add field».
- [ ] Главный seam. `2` открывает поле «Add task to Schedule», группу «Deadline for the new task in Schedule», панели действий нет, Add «Add without deadline» неактивен. Текст, `Tab` — фокус на «No deadline». `M` — фокус в поле, Add «Add · …». `Enter` в пятницу добавляет задачу последней в Schedule с «DUE SOON», поле пустое и в фокусе, Add снова без срока. То же проверить кликом по чипу и по Add, а также `Enter` в поле даты. «+ Time» без даты — сегодня 09:00. `Esc` в ленте. Пустое поле: переход в ленту его не закрывает, уход дальше закрывает. Переезд поля с текстом и сроком. `Esc` и снова `2` — срок сброшен. List view. Телефон. Вошедший без сети: `serverTasks()` со сроком без времени. axe: лента на десктопе и телефоне, в матрице и List view. `inlineAdd.test` «closes an empty field when focus leaves it» переписывается под правило «поле и лента вместе».
- [ ] Чек-лист: начало раздела «T. Добавление со сроком без New task» — клавиатура (`1–4`, текст, `Tab`, чип, `Enter`, `Esc` из ленты, пустое поле и уход фокуса, переезд поля); VoiceOver (группа ленты, «Add · Thu 15 Oct, кнопка»); iPhone (лента над клавиатурой, Add вверху, перенос чипов).

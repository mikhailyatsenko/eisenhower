# 04: «+ Add» в шапках и уход New task

**What to build:** Новичок видит, где добавлять задачи, по подписанной пилюле «+ Add» в шапке каждого квадранта и секции. Плавающая кнопка «New task», её форма и подсказка про клик по пустому месту уходят из приложения вместе с кодом, которым пользовались только они. Это вторая половина среза T [спеки R5](../spec.md), разделы «T. Добавление со сроком без New task» → «“+ Add” и уход “New task”», «Что уходит в T» и «Шпаргалка `?` и страница метода». Решения: [Судьба диалога Edit и плавающей кнопки](../../editing/issues/05-edit-dialog-and-float-button.md); [Как новичок находит добавление без New task](../../editing/issues/06-add-discoverability.md), вариант B прототипа `prototype/add-discoverability` (`?variant=B`). Прототип только для справки.

**Blocked by:** 03 — Лента срока при добавлении. Работа в ветке `ux-r5`. После тикета предложить PR `ux-r5` → `main` (срез T) с проверкой на Vercel preview.

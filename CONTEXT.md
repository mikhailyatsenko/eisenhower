# Eisenhower Matrix

Онлайн-приложение для приоритизации задач по методу Эйзенхауэра: задачи раскладываются по важности и срочности.

## Language

**Matrix**:
Единственный набор задач пользователя, разложенный по четырём квадрантам. У пользователя одна матрица; где она хранится, определяет **Storage**.
_Avoid_: Local Matrix, Cloud Matrix (как отдельные сущности)

**List view**:
Другой вид той же **Matrix**: задачи идут секциями по квадрантам в порядке приоритета, внутри секции в том же порядке, что в квадранте. Своих задач и своего порядка у List view нет.
_Avoid_: Task list (как отдельный список), sorted view

**Storage**:
Место хранения матрицы: на устройстве (анонимный пользователь) или в облаке (вошёл через Google).
_Avoid_: Task source, active state

**Migration**:
Однократный перенос матрицы с устройства в облако при входе в аккаунт. Переносит, а не копирует: локальная копия после него пуста.
_Avoid_: Copy to cloud, sync

**Pending changes**:
Правки вошедшего пользователя, уже применённые на устройстве, но ещё не подтверждённые облаком. Без сети они копятся и уходят сами, когда сеть вернётся; отсутствие сети — не ошибка.
_Avoid_: Unsaved changes, offline error

**Sync error**:
Облако отказалось принять правки (нет доступа, истекла сессия). Отказанные правки откатываются. Если истекла сессия, правки не отказаны: они ждут на устройстве повторного входа в тот же аккаунт. Отсутствие сети sync error не является.
_Avoid_: Offline (как синоним)

**Quadrant**:
Одна из четырёх ячеек матрицы. Называется действием, которое она предписывает; критерии важности и срочности — пояснение, а не имя:
**Do First** (Important & urgent), **Schedule** (Important, not urgent), **Delegate** (Not important, urgent), **Eliminate** (Not important, not urgent).
_Avoid_: Category; «Urgent & Important» и подобные сочетания критериев как название квадранта

**Task**:
Короткая формулировка дела (до 200 символов), лежащая в одном квадранте на определённой позиции.

**Selected Task**:
Одна задача, над которой пользователь сейчас действует. Выделенная задача всегда в фокусе, и при ней открыта панель действий; одновременно выделена не больше одной.
_Avoid_: Active task, focused task (как отдельное состояние)

**Deadline**:
Необязательный момент времени, к которому задачу нужно сделать; после него задача **Overdue**.
_Avoid_: Due date (в UI)

**Completed Task**:
Задача, отмеченная выполненной; уходит из квадранта в архив, помнит исходный квадрант и может быть восстановлена.
_Avoid_: Done, archived task
